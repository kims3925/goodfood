## 🎯 프로젝트 개요

BandAuto는 도매 밴드 자동 수집 및 AI 분석 기반 쇼핑몰 시스템입니다.

### 핵심 기능
- 도매 밴드 게시물 자동 수집
- Gemini AI 상품 분석
- 토스페이먼츠 연동 쇼핑몰
- 소매 밴드 자동 포스팅

### 현재 상태
- ✅ 완료: 85%
- 🚧 진행 중: 10%
- ❌ 미구현: 5%

### Phase 2: Gemini API 키 문제 🟡
**우선순위:** 높음
**예상 시간:** 1-2시간
**의존성:** Phase 1 완료
**상태:** ❌ 대기 중

**증상:**
- AI 모델을 찾을 수 없음
- Gemini API 호출 실패
- 상품 분석 불가

**가설:**
1. API 키 만료 또는 잘못됨
2. Gemini API 엔드포인트 변경
3. 모델 이름 오류 (gemini-pro → gemini-1.5-pro)
4. API 할당량 초과

**해결 방안:**
- [ ] Gemini API 키 재발급
- [ ] 최신 모델 이름 확인
- [ ] API 할당량 확인
- [ ] 에러 메시지 상세 로깅

**세부 문서:**
- 📄 PHASE2_GEMINI_API_FIX.md (작성 예정)

### Phase 3: 장바구니 페이지 구현 🟡
**우선순위:** 높음
**예상 시간:** 2-3시간
**의존성:** 없음
**상태:** ❌ 대기 중

**목표:**
- 장바구니 페이지 생성 (`/store/cart`)
- 장바구니 아이템 목록 표시
- 수량 변경/삭제 기능
- 체크아웃 연결

**필요한 작업:**
1. 페이지 생성: `app/store/cart/page.tsx`
2. 컴포넌트: `components/cart/CartList.tsx`
3. API 연결: 기존 `/api/cart` 활용
4. 체크아웃 연결

**예상 UI:**
```
┌─────────────────────────────────┐
│ 장바구니 (3개 상품)              │
├─────────────────────────────────┤
│ □ [이미지] 상품명                │
│   수량: [- 2 +]  15,000원        │
│   × 삭제                        │
├─────────────────────────────────┤
│ 총 금액: 45,000원                │
│ 배송비: 3,000원                  │
│ ─────────────────               │
│ 결제 금액: 48,000원              │
│                                 │
│ [← 쇼핑 계속하기] [주문하기 →]   │
└─────────────────────────────────┘
```
