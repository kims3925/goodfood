# 리뷰 관리

쇼핑몰에서 구매한 고객이 남긴 상품 리뷰를 조회, 관리하는 페이지입니다. 리뷰 답변 등록, 부적절한 리뷰 블라인드 처리, 베스트 리뷰 선정 등의 기능을 제공합니다.

---

## 화면 구성

### 리뷰 현황 요약

| 카드 | 설명 |
|------|------|
| 전체 리뷰 수 | 등록된 모든 리뷰 건수 |
| 평균 평점 | 쇼핑몰 전체 리뷰 평균 별점 (5점 만점) |
| 미답변 리뷰 | 아직 답변하지 않은 리뷰 건수 |
| 오늘 등록 | 오늘 새로 작성된 리뷰 건수 |

### 리뷰 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 리뷰번호 | RV- 접두사의 리뷰 고유 번호 |
| 상품명 | 리뷰 대상 상품 |
| 작성자 | 리뷰를 남긴 고객 이름 |
| 평점 | ★ 1~5점 |
| 리뷰 내용 | 작성된 리뷰 텍스트 (일부 미리보기) |
| 이미지 | 첨부된 사진 수 |
| 작성일 | 리뷰 등록 날짜 |
| 답변 상태 | 미답변 / 답변완료 |
| 노출 상태 | 공개 / 블라인드 |
| 베스트 | 베스트 리뷰 지정 여부 |

## 주요 기능

### 리뷰 상세 조회

리뷰 번호 또는 리뷰 내용 클릭 시 상세 화면으로 이동합니다.

| 항목 | 내용 |
|------|------|
| 상품 정보 | 리뷰 대상 상품명, 옵션, 구매 날짜 |
| 작성자 정보 | 구매자 이름 (연락처는 미표시) |
| 평점 | 별점 (★ 기준) |
| 리뷰 내용 | 전체 리뷰 텍스트 |
| 첨부 이미지 | 고객이 올린 사진 (클릭 시 원본 크기) |
| 구매 이력 | 실제 구매가 확인된 구매자 여부 |

### 리뷰 답변 등록

- 사장님(운영자) 명의로 답변 텍스트 작성
- 한 리뷰에 하나의 공식 답변만 등록 가능
- 등록된 답변은 쇼핑몰 리뷰 화면에서 "사장님 답변"으로 표시
- 답변 수정 및 삭제 가능

### 블라인드 처리

부적절한 리뷰는 블라인드(비공개) 처리할 수 있습니다.

| 블라인드 사유 | 설명 |
|---------------|------|
| 허위 사실 | 사실과 다른 내용 포함 |
| 욕설/비하 | 비속어 또는 차별적 표현 포함 |
| 개인정보 포함 | 타인의 개인정보가 노출된 경우 |
| 광고성 내용 | 무관한 상업적 홍보 내용 |
| 중복 리뷰 | 동일 내용의 반복 작성 |

- 블라인드 처리된 리뷰는 쇼핑몰 고객에게 노출되지 않습니다.
- 블라인드 사유는 내부 기록으로만 보관됩니다.
- 고객 요청 시 블라인드 해제 가능합니다.

### 베스트 리뷰 선정

- 우수 리뷰를 "베스트 리뷰"로 지정하면 상품 상세 페이지 상단에 노출됩니다.
- 상품당 최대 3개의 베스트 리뷰 선정 가능

## 사용 방법

### 리뷰 답변 등록

1. **리뷰 관리** 페이지에서 미답변 상태 리뷰 클릭
2. 리뷰 내용 및 상품 구매 이력 확인
3. **답변 작성** 영역에 답변 텍스트 입력
4. **답변 등록** 버튼 클릭
5. 쇼핑몰에서 "사장님 답변"으로 노출 확인

### 부적절한 리뷰 블라인드 처리

1. 해당 리뷰 클릭 → 상세 화면 진입
2. **블라인드** 버튼 클릭
3. 블라인드 사유 선택
4. **처리** 버튼 클릭
5. 해당 리뷰는 쇼핑몰에서 즉시 비노출 전환

### 베스트 리뷰 지정

1. 우수 리뷰 클릭 → 상세 화면 진입
2. **베스트 리뷰 지정** 토글 활성화
3. 상품 상세 페이지 상단 베스트 리뷰 영역에 자동 표시

### 리뷰 데이터 내보내기

1. 조회 기간 및 필터 설정
2. **내보내기** 버튼 클릭
3. 엑셀 파일 다운로드 (상품별 평점 분석 활용)

## 주의사항

> **리뷰 삭제 제한**: 고객이 작성한 리뷰는 운영자가 임의로 삭제할 수 없습니다. 부적절한 리뷰는 블라인드 처리를 사용하세요.

- 낮은 별점 리뷰에도 성실한 답변을 등록하면 다른 고객에게 신뢰감을 줄 수 있습니다. 방어적 답변보다 문제 해결 의지를 보여주는 답변을 작성하세요.
- 블라인드 처리는 신중하게 사용하세요. 단순히 부정적인 리뷰라는 이유만으로 블라인드 처리하면 고객 불신을 초래할 수 있습니다.
- 사진 리뷰(이미지 첨부 리뷰)는 쇼핑몰 신뢰도에 크게 기여합니다. 베스트 리뷰 선정 시 사진 리뷰를 우선적으로 고려하세요.
