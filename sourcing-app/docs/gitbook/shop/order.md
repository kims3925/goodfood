# 주문 목록

쇼핑몰에서 발생한 정식 결제 주문을 관리하는 페이지입니다. 주문 상태 변경, 배송정보 입력, 주문 상세 확인 등 주문 처리의 전 과정을 여기서 수행합니다.

![주문 목록 화면](../.gitbook/assets/order-list.png)

---

## 주문 상태 흐름

```
결제완료 → 배송준비 → 배송중 → 배송완료
                ↓
             취소/환불
```

| 상태 | 설명 | 다음 가능 상태 |
|------|------|----------------|
| 결제완료 | 고객이 결제를 마친 상태 | 배송준비, 취소 |
| 배송준비 | 상품 포장 및 출고 준비 중 | 배송중, 취소 |
| 배송중 | 송장번호 등록 완료, 배송 진행 | 배송완료 |
| 배송완료 | 고객 수령 확인 | 환불 |
| 취소 | 고객 또는 운영자 취소 | - |
| 환불 | 배송완료 후 반품/환불 | - |

## 화면 구성

### 주문 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 주문번호 | 고유 주문 식별 코드 |
| 주문일시 | 결제 완료 시각 |
| 고객명 | 구매자 이름 |
| 연락처 | 구매자 전화번호 |
| 상품명 | 주문 상품 (다건 주문 시 대표 상품명 + N건) |
| 결제금액 | 실제 결제된 총액 |
| 결제수단 | 카드 / 계좌이체 / 간편결제 등 |
| 상태 | 현재 주문 처리 상태 |
| 송장번호 | 등록된 운송장 번호 |

### 필터 및 검색

| 필터 | 옵션 |
|------|------|
| 상태 | 전체 / 결제완료 / 배송준비 / 배송중 / 배송완료 / 취소 / 환불 |
| 기간 | 오늘 / 최근 7일 / 최근 30일 / 직접 지정 |
| 검색어 | 주문번호, 고객명, 연락처, 상품명 키워드 |

## 주문 상세 화면

주문번호 클릭 시 주문 상세 화면으로 이동합니다.

### 주문 정보 섹션

| 항목 | 내용 |
|------|------|
| 주문번호 | 시스템 자동 생성 코드 |
| 주문일시 | 결제 완료 시각 |
| 결제수단 | 결제 방법 및 카드사 정보 |
| 결제금액 | 상품금액 + 배송비 - 할인금액 |
| 토스페이먼츠 결제 키 | 결제 취소 시 사용되는 참조 값 |

### 구매자/수령자 정보

| 항목 | 내용 |
|------|------|
| 구매자명 | 결제자 이름 |
| 수령자명 | 배송받을 분 이름 |
| 배송 주소 | 우편번호 포함 상세 주소 |
| 연락처 | 수령자 전화번호 |
| 배송 요청사항 | 고객 입력 배송 메시지 |

### 주문 상품 목록

| 항목 | 내용 |
|------|------|
| 상품명 | 구매 상품 이름 |
| 옵션 | 선택된 옵션 (색상, 사이즈 등) |
| 수량 | 주문 수량 |
| 단가 | 개당 판매가 |
| 소계 | 수량 × 단가 |

## 사용 방법

### 배송 준비 단계로 변경

1. 결제완료 상태 주문 클릭
2. 상태 변경 드롭다운에서 **배송준비** 선택
3. **상태 변경** 버튼 클릭
4. 상품 포장 및 배송사 접수 진행

### 송장번호 등록 (배송중 전환)

1. 배송준비 상태 주문의 상세 화면 진입
2. **배송정보 입력** 섹션에서 배송사 선택
3. 운송장 번호 입력
4. **배송중으로 변경** 버튼 클릭
5. 고객에게 배송 시작 알림 자동 발송 (설정 시)

### 배송 완료 처리

1. 배송중 상태 주문 상세 화면 진입
2. 배송 완료 확인 후 **배송완료** 상태로 변경
3. (고객이 직접 구매 확정 가능)

### 주문 취소 처리

1. 결제완료 또는 배송준비 상태 주문 상세 진입
2. **주문 취소** 버튼 클릭
3. 취소 사유 입력
4. 토스페이먼츠를 통한 자동 결제 취소 진행
5. 취소 완료 시 고객 환불 처리

### 일괄 처리

1. 주문 목록에서 다수 주문 체크박스 선택
2. 상단 **일괄 처리** 드롭다운에서 작업 선택
   - 배송준비로 일괄 변경
   - 엑셀로 내보내기 (송장 업로드용)
3. 확인 후 실행

## 주의사항

> **배송중 상태에서는 취소 불가**: 송장번호를 등록하면 결제 취소가 제한됩니다. 취소가 필요한 경우 배송사에 회수를 요청하고 환불 처리로 진행하세요.

- 토스페이먼츠 결제 취소는 **익일 23:59**까지만 전액 취소가 가능합니다. 이후는 부분 취소만 가능합니다.
- 주문 수정(수량, 상품 변경)은 지원되지 않습니다. 기존 주문 취소 후 재주문을 안내하세요.
- 엑셀 내보내기 기능을 활용하면 배송사 포털에 송장을 일괄 업로드할 수 있습니다.
