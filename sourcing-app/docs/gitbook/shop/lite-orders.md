# 라이트 주문

밴드(Band) 댓글 또는 채팅을 통해 접수된 간편 주문을 관리하는 페이지입니다. 정식 쇼핑몰 결제 시스템을 거치지 않고 밴드에서 직접 주문 의사를 표시한 고객의 주문을 수동으로 처리합니다.

---

## 라이트 주문이란?

밴드 기반 소셜커머스에서는 판매 게시물의 댓글이나 밴드 채팅으로 "주문할게요", "1개 주세요" 와 같이 비정형 텍스트로 주문이 접수되는 경우가 많습니다. 라이트 주문은 이러한 비정형 주문을 체계적으로 관리할 수 있도록 설계된 기능입니다.

| 구분 | 정식 주문 | 라이트 주문 |
|------|-----------|-------------|
| 접수 경로 | 쇼핑몰 장바구니 → 결제 | 밴드 댓글 / 채팅 |
| 결제 방식 | 토스페이먼츠 온라인 결제 | 계좌이체, 현금, 추후 결제 |
| 자동화 수준 | 전자동 (결제 → 주문 생성) | 반자동 (접수 확인 → 수동 등록) |
| 주요 사용 사례 | 일반 온라인 구매 고객 | 밴드 충성 고객, 단골 구매자 |

## 화면 구성

### 라이트 주문 목록

| 컬럼 | 설명 |
|------|------|
| 주문번호 | LO- 접두사의 라이트 주문 번호 |
| 접수일시 | 담당자가 등록한 시각 |
| 고객명 | 밴드 닉네임 또는 실명 |
| 연락처 | 고객 연락처 (수동 입력) |
| 상품명 | 주문 상품 |
| 수량 | 주문 수량 |
| 금액 | 결제 예정 또는 완료 금액 |
| 결제 방법 | 계좌이체 / 현금 / 미정 |
| 상태 | 접수 / 입금확인 / 배송중 / 완료 |
| 밴드 출처 | 어느 밴드 채널에서 접수된 주문인지 |

### 필터

| 필터 | 옵션 |
|------|------|
| 상태 | 전체 / 접수 / 입금확인 / 배송중 / 완료 / 취소 |
| 밴드 채널 | 연결된 밴드 채널 목록 |
| 기간 | 접수일 기준 날짜 범위 |
| 검색어 | 고객명, 연락처, 상품명 |

## 주요 기능

### 라이트 주문 상태 흐름

```
접수 → 입금확인 → 배송중 → 완료
  ↓
 취소
```

| 상태 | 설명 |
|------|------|
| 접수 | 밴드에서 주문 의사를 확인하고 등록한 상태 |
| 입금확인 | 계좌이체 또는 현금 입금을 확인한 상태 |
| 배송중 | 상품 발송 및 송장번호 등록 완료 |
| 완료 | 고객 수령 및 거래 완료 |
| 취소 | 주문 취소 처리 |

### 밴드 댓글 자동 파싱

밴드 채널과 연동된 경우, 댓글에서 주문 정보를 자동으로 파싱하여 라이트 주문 목록에 추가할 수 있습니다.

- 파싱 패턴: "상품명 N개", "OOO 주문합니다", "1개 구매" 등 키워드 인식
- 파싱 후 담당자 검토 → 확정 버튼으로 주문 등록

### 발주 연동

라이트 주문이 누적되면 **발주 관리** 페이지에서 일괄 발주서를 생성할 수 있습니다. 라이트 주문의 상품별 수량이 자동으로 집계됩니다.

## 사용 방법

### 라이트 주문 수동 등록

1. **라이트 주문** 페이지에서 **주문 추가** 버튼 클릭
2. 고객 정보 입력
   - 고객명 (밴드 닉네임 또는 실명)
   - 연락처
   - 배송 주소
3. 주문 상품 추가
   - 상품 검색 후 선택
   - 수량 입력
4. 결제 방법 선택 (계좌이체 / 현금 / 미정)
5. 밴드 채널 연결 (출처 기록용)
6. **저장** 버튼 클릭

### 입금 확인 처리

1. 고객으로부터 계좌이체 완료 연락 수신
2. 라이트 주문 목록에서 해당 주문 클릭
3. 입금 금액 확인 후 **입금확인** 버튼 클릭
4. 입금 확인 일시 자동 기록

### 배송 처리

1. 입금확인 상태 주문 상세 화면 진입
2. 배송사 및 송장번호 입력
3. **배송중으로 변경** 버튼 클릭
4. 고객에게 카카오톡 또는 문자로 송장번호 안내

---

## 주의사항

> **라이트 주문은 토스페이먼츠를 통한 자동 결제가 아닙니다.** 입금 확인은 담당자가 직접 계좌를 확인하고 수동으로 처리해야 합니다.

- 라이트 주문 고객의 연락처와 주소는 반드시 직접 확인하세요. 밴드 댓글만으로는 배송에 필요한 정보가 부족할 수 있습니다.
- 계좌이체 입금 확인 시, 입금자명과 주문자명이 다를 경우 고객에게 재확인 후 처리하세요.
- 라이트 주문은 쇼핑몰 정산에 자동 포함되지 않습니다. 별도로 **도매 정산서** 또는 수기 정산으로 관리하세요.
