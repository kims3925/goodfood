# 도매 정산서

도매처별로 매입 금액을 정산하는 문서를 생성하고 관리하는 페이지입니다. 발주 및 판매 데이터를 기반으로 도매처에 지급해야 할 금액을 자동 계산하고, 정산서를 발행하여 도매처와 공유할 수 있습니다.

---

## 도매 정산서란?

소매 쇼핑몰 운영자가 도매처(공급처)에 지급해야 할 금액을 계산한 문서입니다. 발주 수량과 실제 판매 수량을 비교하고, 반품/미납 등을 고려하여 정확한 도매 정산 금액을 도출합니다.

| 구분 | 소매 정산 (정산 목록) | 도매 정산서 |
|------|----------------------|-------------|
| 방향 | 쇼핑몰 → 운영자 (수취) | 운영자 → 도매처 (지급) |
| 기준 | 고객 결제 금액 기반 | 도매 매입가 × 실 판매량 기반 |
| 대상 | 쇼핑몰 판매 수익 정산 | 도매처 지급 금액 정산 |

| 정산 기간 | 정산 대상 판매 기간 |

| 판매 총량 | 기간 내 실제 판매된 수량 합계 |

| 정산 금액 | 도매처에 지급할 최종 금액 |
| 상태 | 작성중 / 확인요청 / 정산완료 |

### 도매 정산서 상세

| 항목 | 설명 |
|------|------|
| 상품명 | 도매처로부터 공급받은 상품 |
| 도매 상품코드 | 도매처 기준 상품 코드 |
| 옵션 | 색상, 사이즈 등 옵션별 집계 |
| 발주 수량 | 해당 기간 발주한 총 수량 |
| 판매 수량 | 실제 고객에게 판매된 수량 |
| 반품 수량 | 환불/반품 처리된 수량 |
| 정산 수량 | 판매 수량 - 반품 수량 |
| 도매 단가 | 개당 매입가 |
| 소계 | 정산 수량 × 도매 단가 |

## 주요 기능

### 도매 정산서 자동 생성

발주 데이터와 판매 데이터를 기반으로 도매처별 정산서를 자동으로 계산합니다.

| 단계 | 내용 |
|------|------|
| 1 | 기간 내 발주 완료된 발주서 목록 조회 |
| 2 | 발주 상품별 판매 수량 집계 (주문 목록 연동) |
| 3 | 환불/반품 수량 차감 |
| 4 | 도매가 × 정산 수량 = 도매처 지급 금액 계산 |
| 5 | 도매처별로 자동 분리된 정산서 생성 |

### 정산서 공유 기능

| 공유 방식 | 설명 |
|-----------|------|
| PDF 다운로드 | 인쇄 가능한 정식 정산서 PDF |
| 엑셀 내보내기 | 상세 데이터 포함 엑셀 파일 |
| 링크 공유 | 도매처가 직접 조회할 수 있는 공유 링크 (선택) |
| 텍스트 복사 | 카카오톡 전송용 정산 내역 텍스트 |

**텍스트 복사 형식 예시:**
```
[도매 정산서] OOO 쇼핑몰 2024년 1월분

도매처: 신선수산 OOO
정산 기간: 2024-01-01 ~ 2024-01-31

상품명 | 판매수량 | 반품수량 | 정산수량 | 단가 | 소계
갈치 500g | 100 | 3 | 97 | 8,000 | 776,000원
고등어 1kg | 80 | 1 | 79 | 12,000 | 948,000원

합계: 1,724,000원
```

## 사용 방법

### 도매 정산서 생성

1. **도매 정산서** 페이지에서 **정산서 생성** 버튼 클릭
2. 정산 기간 설정 (시작일 ~ 종료일)
3. 도매처 선택 (전체 또는 특정 도매처)
4. 자동 계산된 정산 내역 검토
   - 판매 수량 / 반품 수량 / 정산 수량 확인
   - 도매가 적용 여부 확인
5. 수동 수정이 필요한 항목 조정
6. **정산서 저장** 버튼 클릭

### 도매처에 정산서 전달

1. 생성된 도매 정산서 클릭
2. **공유** 버튼 선택
3. 공유 방법 선택:
   - PDF 다운로드 후 이메일/카카오톡 첨부 전송
   - 텍스트 복사 후 채팅으로 전달
4. 도매처에 정산서 확인 요청
5. 도매처 확인 후 **확인요청** 상태로 변경

### 정산 완료 처리

1. 도매처에 대금 지급 완료
2. 해당 정산서 클릭 → **정산완료** 버튼 클릭
3. 지급일 및 지급 금액 입력
4. 완료 처리 → 정산 이력에 기록

## 주의사항

> **발주 기반 정산**: 도매 정산서는 발주 완료된 주문 기반으로 계산됩니다. 발주 관리 페이지에서 발주 상태를 정확히 관리해야 정산 금액의 오차를 줄일 수 있습니다.

- 도매처별 단가가 다른 경우, 상품 관리 페이지에서 상품별 원가(도매가)를 정확히 입력해두어야 정산 금액이 올바르게 계산됩니다.
- 반품 수량은 쇼핑몰에서 환불 처리된 건을 기준으로 합니다. 실제 도매처로 반품된 수량과 다를 경우 수동 조정이 필요합니다.
- 월말에 정산하는 경우, 해당 월의 마지막 날 이후 발생한 환불이 정산에 포함되지 않을 수 있습니다. 정산 기간을 충분히 고려하여 설정하세요.
