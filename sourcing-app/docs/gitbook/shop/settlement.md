# 정산 목록

쇼핑몰 판매 내역을 기반으로 기간별 정산 현황을 조회하고 관리하는 페이지입니다. 판매 금액, 수수료, 배송비, 환불 금액 등을 종합하여 실제 정산 예정 금액을 확인할 수 있습니다.

---

## 화면 구성

### 정산 요약 카드

| 카드 | 설명 |
|------|------|
| 정산 예정 금액 | 아직 지급되지 않은 정산 대기 금액 |
| 이번 달 정산 | 이번 달 확정된 정산 금액 합계 |
| 누적 정산 금액 | 전체 기간 누적 정산 완료 금액 |
| 정산 건수 | 정산 완료 / 대기 건수 |

### 정산 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 정산번호 | SA- 접두사의 정산 고유 번호 |
| 정산 기간 | 해당 정산이 포함하는 판매 기간 |
| 생성일 | 정산서가 생성된 날짜 |
| 판매 금액 | 기간 내 총 판매액 (결제 완료 기준) |
| 환불 금액 | 기간 내 환불 처리 금액 |
| 수수료 | 플랫폼/PG 수수료 |
| 배송비 | 수취한 배송비 총합 |
| 정산 금액 | 판매금액 - 환불 - 수수료 + 배송비 |
| 상태 | 대기 / 정산완료 |

### 정산 금액 계산 공식

```
정산 금액 = 판매 금액 - 환불 금액 - 결제 수수료 - 플랫폼 수수료
```

| 항목 | 기준 | 비율/금액 |
|------|------|-----------|
| 결제 수수료 (카드) | 결제 금액의 % | 토스페이먼츠 계약 기준 |
| 결제 수수료 (간편결제) | 결제 금액의 % | 결제 수단별 상이 |
| 플랫폼 수수료 | 판매 금액의 % | BandAuto 계약 기준 |
| 배송비 수취 | 고객 결제 배송비 | 전액 정산 포함 |

## 주요 기능

### 기간별 정산 조회

| 조회 옵션 | 설명 |
|-----------|------|
| 기간 직접 지정 | 시작일 ~ 종료일 설정 |
| 월별 조회 | 특정 연월 선택 |
| 주별 조회 | 특정 주차 선택 |
| 전체 | 등록된 모든 정산 내역 |

### 정산 상세 내역

정산번호 클릭 시 해당 정산에 포함된 주문 상세 내역 확인 가능:

| 항목 | 설명 |
|------|------|
| 포함 주문 목록 | 해당 기간 결제 완료된 주문 전체 |
| 상품별 판매 집계 | 상품별 판매 수량 및 금액 |
| 결제 수단별 집계 | 카드/계좌이체/간편결제별 금액 분포 |
| 환불 내역 | 기간 내 환불 처리된 주문 목록 |

### 정산서 내보내기

| 형식 | 내용 |
|------|------|
| 엑셀 (.xlsx) | 정산 상세 내역 전체 |
| PDF | 인쇄용 정산서 (공식 문서 형식) |

## 사용 방법

### 기간별 정산 조회

1. **정산 목록** 페이지 접속
2. 상단 기간 필터에서 조회할 날짜 범위 설정
3. **조회** 버튼 클릭
4. 정산 목록에서 해당 기간의 정산 내역 확인

### 정산서 생성 (수동)

1. **정산 목록** 페이지에서 **정산서 생성** 버튼 클릭
2. 정산 기간 설정 (시작일 ~ 종료일)
3. 포함할 주문 상태 확인 (기본: 배송완료)
4. **생성** 버튼 클릭
5. 생성된 정산서 내용 검토

### 정산 완료 처리

1. 실제 지급 완료 후 해당 정산서 클릭
2. **정산완료** 버튼 클릭
3. 지급일, 지급 금액 확인
4. 완료 처리 → 정산 이력으로 이동

### 정산서 내보내기

1. 해당 정산번호 클릭 → 상세 화면 진입
2. 우상단 **내보내기** 버튼 클릭
3. 엑셀 또는 PDF 선택 후 다운로드

## 주의사항

> **정산 기준**: 기본 정산 기준은 **결제 완료** 기준입니다. 배송완료 기준으로 정산이 필요한 경우 설정에서 변경 가능합니다.

- 결제 수수료는 토스페이먼츠와의 계약 조건에 따라 다를 수 있습니다. 수수료율을 변경하려면 소싱 앱 설정 > 결제 설정에서 조정하세요.
- 환불된 주문은 해당 기간 정산 금액에서 자동 차감됩니다. 환불일이 다른 기간에 포함될 경우 차감 기간이 달라질 수 있습니다.
- 정산서 생성 후 추가로 결제/환불이 발생하면 정산 금액이 변경될 수 있습니다. 최종 확정 전에 반드시 검토하세요.
