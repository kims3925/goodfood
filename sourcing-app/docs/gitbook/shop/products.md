# 상품 관리

쇼핑몰에 노출되는 상품을 등록, 수정, 삭제하고 카테고리를 관리하는 페이지입니다. AI 카테고리 자동 분류 기능을 활용하면 다수의 상품을 빠르게 정리할 수 있습니다.

---

## 화면 구성

### 상품 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 썸네일 | 대표 이미지 미리보기 |
| 상품명 | 쇼핑몰 노출 상품명 |
| 카테고리 | 분류 카테고리 (다중 선택 가능) |
| 판매가 | 고객 노출 가격 |
| 원가 | 매입 원가 (내부용) |
| 재고 | 현재 재고 수량 |
| 상태 | 판매중 / 품절 / 숨김 / 삭제됨 |
| 소싱 출처 | 연결된 소싱 채널 |
| 등록일 | 쇼핑몰 등록 날짜 |

### 필터 및 검색

| 필터 | 옵션 |
|------|------|
| 상태 | 전체 / 판매중 / 품절 / 숨김 |
| 카테고리 | 등록된 카테고리 목록 |
| 소싱 채널 | 연결된 밴드 채널 |
| 기간 | 등록일 기준 날짜 범위 |
| 검색어 | 상품명, 상품코드 키워드 검색 |

---

## 주요 기능

### 상품 상세 편집

상품명 클릭 또는 편집(✏️) 아이콘 클릭 시 상세 편집 화면으로 이동합니다.

**기본 정보 탭**

| 항목 | 설명 |
|------|------|
| 상품명 | 쇼핑몰 노출 명칭 (최대 100자) |
| 상품 설명 | 리치 텍스트 에디터 지원 (이미지 삽입 가능) |
| 대표 이미지 | 썸네일 및 상세 이미지 (최대 10장) |
| 카테고리 | 1차/2차 카테고리 선택 |
| 태그 | 검색 노출용 태그 (콤마 구분) |

**가격 및 재고 탭**

| 항목 | 설명 |
|------|------|
| 판매가 | 고객 결제 금액 |
| 할인가 | 할인 적용 시 표시 가격 |
| 원가 | 매입 원가 (마진 계산용, 고객 비노출) |
| 재고 수량 | 현재 판매 가능 재고 |
| 재고 관리 | 재고 소진 시 자동 품절 전환 여부 |
| 옵션 | 색상, 사이즈 등 옵션별 재고/가격 설정 |

**배송 탭**

| 항목 | 설명 |
|------|------|
| 배송비 유형 | 기본 배송비 사용 / 개별 배송비 설정 |
| 개별 배송비 | 해당 상품에만 적용되는 별도 배송비 |
| 출고지 | 상품별 출고지 지정 (기본값: 쇼핑몰 설정) |

### 카테고리 관리

- **카테고리 추가**: 카테고리명 입력 후 저장
- **2단계 계층 구조**: 상위 카테고리 > 하위 카테고리
- **노출 순서 변경**: 드래그 앤 드롭으로 정렬
- **카테고리 삭제**: 해당 카테고리에 속한 상품이 없을 때만 삭제 가능

### AI 카테고리 자동 분류

소싱 앱에서 수집된 상품은 **Gemini AI**를 활용하여 카테고리를 자동으로 분류합니다.

| 단계 | 내용 |
|------|------|
| 1 | 상품명 + 설명 텍스트를 AI에 전달 |
| 2 | Gemini가 등록된 카테고리 목록과 매칭 분석 |
| 3 | 가장 적합한 카테고리 추천 (신뢰도 점수 포함) |
| 4 | 담당자 최종 확인 후 적용 또는 수동 변경 |

- **일괄 분류**: 상품 목록에서 다중 선택 후 "AI 카테고리 자동 분류" 버튼 실행
- **분류 정확도**: 카테고리 설명이 구체적일수록 정확도가 높아집니다

## 사용 방법

### 상품 직접 등록

1. **상품 관리** 페이지에서 **상품 추가** 버튼 클릭
2. 상품명, 설명, 이미지 입력
3. 카테고리, 가격, 재고 설정
4. 배송 정보 확인 후 **저장** 클릭
5. 상태를 "판매중"으로 변경하여 쇼핑몰에 노출

### 소싱 상품을 쇼핑몰에 등록

1. **소싱 > 상품 목록**에서 발행할 상품 선택
2. "쇼핑몰 발행" 버튼 클릭
3. 가격, 재고, 카테고리 확인 후 발행 완료
4. **상품 관리** 페이지에서 발행된 상품 확인

### AI 카테고리 일괄 분류

1. 카테고리 미지정 상품 필터 적용
2. 전체 선택 (체크박스 헤더 클릭)
3. "AI 카테고리 자동 분류" 버튼 클릭
4. 분류 결과 검토 후 이상 항목 수동 수정
5. **일괄 저장** 버튼으로 확정

## 주의사항

> **소프트 삭제**: 상품 삭제는 실제 DB에서 제거되지 않고 "삭제됨" 상태로 변경됩니다. 복원이 필요하면 관리자에게 문의하세요.

- 재고가 0이 되면 자동으로 "품절" 상태로 전환됩니다. 단, 재고 관리 옵션을 OFF로 설정하면 재고와 무관하게 판매 가능 상태를 유지합니다.
- 원가 정보는 고객에게 노출되지 않으며 마진율 계산과 정산 기준으로만 사용됩니다.
- 이미지는 각 1MB 이하, JPG/PNG 형식을 권장합니다.
