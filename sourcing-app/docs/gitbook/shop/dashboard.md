# 쇼핑몰 대시보드

쇼핑몰의 전반적인 운영 현황을 한눈에 파악할 수 있는 메인 대시보드입니다. 매출, 주문, 인기 상품, 최근 주문 현황을 실시간으로 확인하고 빠른 의사결정을 내릴 수 있습니다.

![쇼핑몰 대시보드 화면](../.gitbook/assets/shop-dashboard.png)

---

## 화면 구성

### 상단 요약 카드

| 카드 | 표시 정보 | 갱신 주기 |
|------|-----------|-----------|
| 오늘 매출 | 당일 결제 완료 금액 합계 | 실시간 |
| 이번 달 매출 | 월 누적 결제 금액 | 실시간 |
| 신규 주문 | 오늘 접수된 주문 건수 | 실시간 |
| 처리 대기 | 배송 준비 단계 미처리 주문 수 | 실시간 |

### 매출 추이 그래프

- **기간 선택**: 최근 7일 / 30일 / 3개월 탭 전환
- **차트 유형**: 일별 막대 그래프 + 누적 매출 꺾은선 그래프 병행 표시
- **비교 기능**: 전주/전월 동기 대비 증감율(%) 표시

### 주문 상태 도넛 차트

| 상태 | 색상 | 설명 |
|------|------|------|
| 결제완료 | 파랑 | 결제 후 배송 준비 미착수 |
| 배송준비 | 노랑 | 출고 준비 중 |
| 배송중 | 주황 | 송장 등록 완료, 배송 진행 |
| 배송완료 | 초록 | 수령 확인 |
| 취소/환불 | 빨강 | 취소 및 환불 처리 완료 |

### 인기 상품 TOP 5

- 판매 수량 기준 상위 5개 상품 자동 정렬
- 상품명, 판매량, 매출액, 재고 현황 표시
- 재고 10개 이하 시 ⚠️ 아이콘으로 경고 표시
- 상품명 클릭 시 해당 상품 상세 편집 페이지로 이동

### 최근 주문 목록

- 최신 10건의 주문을 시간 역순으로 표시
- 표시 항목: 주문번호, 고객명, 상품명, 금액, 상태, 주문 시각
- "전체 보기" 버튼 클릭 시 주문 목록 페이지로 이동

---

## 사용 방법

1. **대시보드 접속**: 소싱 앱 좌측 메뉴에서 **쇼핑몰 > 대시보드** 클릭
2. **기간 변경**: 매출 그래프 우상단의 기간 탭(7일/30일/3개월)을 선택하여 원하는 범위 조회
3. **처리 대기 주문 확인**: 상단 요약 카드의 "처리 대기" 숫자 클릭 시 해당 상태 주문 목록으로 바로 이동
4. **인기 상품 재고 보충**: 인기 상품 목록에서 ⚠️ 경고가 표시된 상품을 확인하고 재고를 추가 등록
5. **최근 주문 처리**: 최근 주문 목록에서 결제완료 상태 주문을 클릭하여 배송 준비 단계로 전환

---

## 주의사항

> **매출 기준**: 대시보드의 매출 수치는 **결제 완료** 기준으로 집계됩니다. 취소/환불 건은 별도 차감되지 않으므로 정확한 순매출은 정산 목록에서 확인하세요.

- 대시보드는 최대 5분 단위로 자동 갱신됩니다. 즉시 갱신이 필요하면 브라우저 새로고침(F5)을 사용하세요.
- 처리 대기 주문이 누적되면 고객 불만으로 이어질 수 있습니다. 매일 오전 업무 시작 시 대시보드를 확인하는 것을 권장합니다.
- 인기 상품의 재고가 부족한 경우 **발주 관리** 메뉴를 통해 도매처에 즉시 발주하세요.
