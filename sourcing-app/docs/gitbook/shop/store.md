# 쇼핑몰 관리

쇼핑몰의 기본 정보, 시각적 요소(배너/로고), 배송 정책, 결제 수단 등 쇼핑몰 운영에 필요한 핵심 설정을 관리하는 페이지입니다.

---

## 주요 기능

### 쇼핑몰 기본 정보

| 항목 | 설명 | 필수 여부 |
|------|------|-----------|
| 쇼핑몰 이름 | 고객에게 노출되는 쇼핑몰 명칭 | 필수 |
| 쇼핑몰 설명 | 쇼핑몰 소개 문구 (최대 200자) | 선택 |
| 사업자 등록번호 | 법적 사업자 정보 | 선택 |
| 대표 연락처 | 고객 문의 수신 전화번호 | 필수 |
| 대표 이메일 | 고객 문의 수신 이메일 | 필수 |
| 운영 시간 | 고객 응대 가능 시간 안내 | 선택 |

### 배너 및 로고 관리

| 항목 | 권장 사이즈 | 지원 형식 |
|------|-------------|-----------|
| 쇼핑몰 로고 | 200 × 80 px | PNG, JPG, SVG |
| 메인 배너 | 1200 × 400 px | PNG, JPG |
| 모바일 배너 | 750 × 300 px | PNG, JPG |
| 파비콘 | 32 × 32 px | PNG, ICO |

- 배너는 최대 5장까지 등록 가능하며 슬라이드 형태로 표시됩니다.
- 각 배너에 링크(상품 페이지 or 외부 URL)를 지정할 수 있습니다.
- 드래그 앤 드롭으로 배너 노출 순서를 변경할 수 있습니다.

### 배송 정책 설정

| 설정 항목 | 옵션 |
|-----------|------|
| 기본 배송비 | 직접 입력 (원) |
| 무료 배송 기준금액 | 설정금액 이상 구매 시 무료 배송 |
| 배송사 | CJ대한통운, 로젠, 한진, 우체국 등 |
| 출고지 주소 | 실제 상품 발송 장소 |
| 배송 소요일 | 평균 배송 기간 안내 문구 |
| 도서산간 추가 배송비 | 지역별 추가 요금 설정 |

### 토스페이먼츠 결제 연동

BandAuto는 **토스페이먼츠(TossPayments)** SDK를 통해 결제를 처리합니다.

| 설정 항목 | 설명 |
|-----------|------|
| 클라이언트 키 | 토스페이먼츠 대시보드에서 발급 |
| 시크릿 키 | 서버 사이드 결제 승인용 (외부 노출 금지) |
| 결제 수단 | 카드, 계좌이체, 가상계좌, 간편결제 선택 |
| 테스트 모드 | 개발/테스트 환경에서 실결제 없이 검증 |

지원 결제 수단:
- 신용카드 / 체크카드
- 카카오페이 / 네이버페이 / 삼성페이
- 계좌이체 / 가상계좌
- 휴대폰 소액결제

## 사용 방법

### 쇼핑몰 기본 정보 수정

1. **쇼핑몰 관리** 페이지 접속
2. "기본 정보" 탭 선택
3. 쇼핑몰 이름, 연락처 등 항목 수정
4. **저장** 버튼 클릭

### 배너 등록

1. "배너/로고" 탭 선택
2. **배너 추가** 버튼 클릭
3. 이미지 파일 업로드 (권장 사이즈 준수)
4. 배너 연결 링크 입력 (선택)
5. **저장** 버튼 클릭

### 토스페이먼츠 연동

1. [토스페이먼츠 개발자 센터](https://developers.tosspayments.com) 접속 후 API 키 발급
2. "결제 설정" 탭 선택
3. 클라이언트 키, 시크릿 키 입력
4. 테스트 모드 ON 상태에서 결제 흐름 검증
5. 실서비스 운영 시 테스트 모드 OFF 전환

---

## 주의사항

> **시크릿 키 보안**: 토스페이먼츠 시크릿 키는 절대 외부에 노출되어서는 안 됩니다. 클라이언트 코드(JavaScript)에 포함하지 마세요.

- 배너 이미지를 변경한 경우 고객 브라우저 캐시로 인해 즉시 반영되지 않을 수 있습니다. (보통 1~5분 소요)
- 무료 배송 기준금액을 변경하면 이미 장바구니에 담긴 고객의 배송비에도 즉시 반영됩니다.
- 결제 수단 변경 시 진행 중인 주문에는 영향을 주지 않습니다.
