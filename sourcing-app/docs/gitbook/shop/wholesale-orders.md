# 발주 관리

쇼핑몰 주문 및 라이트 주문을 기반으로 도매처에 상품을 발주하는 페이지입니다. 주문 수량을 자동으로 집계하여 발주서를 생성하고, 발주 텍스트를 복사하여 도매처에 빠르게 전달할 수 있습니다.

---

## 발주 프로세스 개요

```
주문 접수 (정식/라이트)
       ↓
발주 관리 페이지에서 주문 수량 집계
       ↓
발주서 생성 (도매처별)
       ↓
발주 텍스트 복사 → 도매처 전달 (카카오톡/문자/이메일)
       ↓
도매처 발송 → 입고 확인
       ↓
고객 배송 처리
```

## 화면 구성

### 발주 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 발주번호 | PO- 접두사의 발주 고유 번호 |
| 발주일시 | 발주서 생성 날짜 및 시각 |
| 도매처명 | 발주 대상 도매처 |
| 발주 상품 수 | 발주서에 포함된 상품 종류 수 |
| 발주 총량 | 전체 발주 수량 합계 |
| 발주 금액 | 도매가 기준 총 발주 금액 |
| 상태 | 작성중 / 발주완료 / 입고완료 / 취소 |
| 처리자 | 발주서를 생성한 담당자 |

### 발주서 상세

| 항목 | 설명 |
|------|------|
| 상품명 | 발주할 상품 이름 |
| 상품코드 | 도매처 상품 코드 (매핑된 경우) |
| 옵션 | 색상, 사이즈 등 옵션별 구분 |
| 발주 수량 | 집계된 주문 수량 |
| 도매가 | 개당 매입 단가 |
| 소계 | 수량 × 도매가 |
| 연결 주문 | 이 발주에 포함된 주문 번호 목록 |

## 주요 기능

### 주문 기반 자동 수량 집계

미처리 정식 주문 및 라이트 주문에서 상품별 수량을 자동으로 집계합니다.

| 집계 기준 | 설명 |
|-----------|------|
| 정식 주문 | 결제완료 / 배송준비 상태의 주문 |
| 라이트 주문 | 접수 / 입금확인 상태의 주문 |
| 제외 기준 | 이미 이전 발주서에 포함된 주문 |

**도매처별 분리**: 상품에 연결된 도매처가 다르면 자동으로 도매처별 발주서를 분리 생성합니다.

### 발주서 생성

1. **새 발주서 만들기** 버튼 클릭
2. 기간 선택 (어떤 주문을 포함할지)
3. 도매처 선택 (전체 또는 특정 도매처)
4. 집계된 상품 목록 확인 및 수량 수동 조정
5. 발주서 저장

### 발주 텍스트 복사

도매처에 카카오톡이나 문자로 발주 내역을 전달할 수 있도록 정형화된 텍스트를 자동 생성합니다.

**생성 형식 예시:**
```
[발주 요청] OOO 쇼핑몰 2024-01-15

상품코드 | 상품명 | 옵션 | 수량
A001 | 사과즙 100ml | - | 50개
B002 | 한우 불고기 500g | - | 30개
C003 | 제주 감귤 3kg | 특상 | 20개

총 발주 수량: 100개
총 발주 금액: 1,250,000원
```

- **복사 버튼**: 클립보드에 텍스트 복사 (카카오톡, 문자 등에 붙여넣기)
- **엑셀 내보내기**: 도매처 포털 업로드용 엑셀 파일 다운로드

## 사용 방법

### 발주서 생성 및 전달

1. **발주 관리** 페이지에서 **새 발주서 만들기** 클릭
2. 발주 대상 기간 설정 (예: 오늘 접수된 주문)
3. 도매처별로 자동 분류된 발주 수량 확인
4. 필요 시 수량 수동 조정 (예: 안전 재고분 추가)
5. **발주서 저장** 버튼 클릭
6. 발주서 상세 화면에서 **발주 텍스트 복사** 버튼 클릭
7. 도매처 담당자에게 카카오톡 또는 이메일로 전달
8. 발주 전달 후 상태를 **발주완료**로 변경

### 입고 확인 처리

1. 도매처로부터 상품 수령
2. 해당 발주서 상세 화면 진입
3. 입고 수량 확인 (발주 수량과 비교)
4. **입고완료** 상태로 변경
5. 재고 수량 자동 업데이트 (상품 관리와 연동)

### 발주 취소

1. 발주완료 이전 상태에서만 취소 가능
2. 발주서 상세 화면에서 **취소** 버튼 클릭
3. 취소 사유 입력 후 확정
4. 해당 발주에 포함된 주문들은 다시 미발주 상태로 복원

---

## 주의사항

> **재고 관리와의 연동**: 입고완료 처리 시 상품 재고 수량이 자동으로 증가합니다. 실제 입고 수량과 다를 경우 상품 관리 페이지에서 재고를 직접 수정하세요.

- 발주서 생성 전, 이미 이전 발주에 포함된 주문이 중복 집계되지 않는지 확인하세요. 발주 상태가 **발주완료** 이상인 발주서에 포함된 주문은 자동으로 제외됩니다.
- 도매처에 발주 텍스트를 전달한 후 반드시 **발주완료** 상태로 변경해야 이후 집계에서 중복이 방지됩니다.
- 여러 도매처에서 상품을 조달하는 경우, 도매처별 발주서를 각각 관리하는 것이 정산 시 편리합니다.
