# 고객 문의

쇼핑몰 고객이 등록한 CS(Customer Service) 문의 목록을 조회하고 답변을 등록하는 페이지입니다. 미답변 문의를 빠르게 처리하여 고객 만족도를 높일 수 있습니다.

---

## 화면 구성

### 문의 현황 요약

| 카드 | 설명 |
|------|------|
| 전체 문의 | 접수된 전체 문의 건수 |
| 미답변 | 아직 답변하지 않은 문의 건수 |
| 답변 완료 | 답변이 등록된 문의 건수 |
| 오늘 접수 | 오늘 새로 접수된 문의 건수 |

### 문의 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 문의번호 | QNA- 접두사의 문의 고유 번호 |
| 문의 유형 | 배송 / 상품 / 결제 / 교환반품 / 기타 |
| 제목 | 고객이 입력한 문의 제목 |
| 작성자 | 문의한 고객 이름 또는 닉네임 |
| 연관 주문 | 문의와 연결된 주문번호 (있는 경우) |
| 연관 상품 | 문의 대상 상품명 |
| 접수일 | 문의 등록 날짜 및 시각 |
| 상태 | 미답변 / 답변완료 / 처리중 / 완료 |
| 처리자 | 답변을 등록한 담당자 |

### 필터 및 검색

| 필터 | 옵션 |
|------|------|
| 상태 | 전체 / 미답변 / 답변완료 / 처리중 |
| 문의 유형 | 전체 / 배송 / 상품 / 결제 / 교환반품 / 기타 |
| 기간 | 접수일 기준 날짜 범위 |
| 검색어 | 문의 제목, 고객명, 주문번호, 상품명 |

## 주요 기능

### 문의 유형별 분류

| 유형 | 주요 내용 |
|------|-----------|
| 배송 | 배송 위치 문의, 배송 지연, 미수령 |
| 상품 | 상품 불량, 사진과 다름, 사이즈 문의 |
| 결제 | 결제 오류, 영수증 요청, 결제 취소 |
| 교환/반품 | 교환 요청, 반품 절차 문의 |
| 기타 | 위 유형에 해당하지 않는 문의 |

### 답변 등록

- **기본 답변**: 텍스트 에디터에서 답변 직접 작성
- **템플릿 답변**: 자주 사용하는 답변 문구를 템플릿으로 저장하여 빠르게 삽입
- **이미지 첨부**: 답변에 이미지 첨부 가능 (상품 이미지, 배송 안내 등)
- **비공개 메모**: 내부 담당자만 볼 수 있는 처리 메모 기록

### 자주 쓰는 답변 템플릿

| 템플릿명 | 활용 상황 |
|----------|-----------|
| 배송 조회 안내 | 송장번호와 조회 링크 안내 |
| 교환/반품 절차 | 교환·반품 방법 단계별 안내 |
| 환불 처리 완료 | 환불 완료 및 소요 기간 안내 |
| 재고 부족 안내 | 품절 상품 입고 예정 안내 |
| 상품 불량 사과 | 불량 확인 후 처리 절차 안내 |

## 사용 방법

### 문의 답변 등록

1. **고객 문의** 페이지에서 미답변 상태 문의 클릭
2. 문의 내용 및 연관 주문/상품 확인
3. **답변 작성** 영역에 답변 텍스트 입력
4. 필요 시 **템플릿 불러오기** 버튼으로 템플릿 삽입 후 수정
5. **답변 등록** 버튼 클릭
6. 상태 자동으로 **답변완료**로 변경
7. 고객에게 답변 등록 알림 자동 발송 (설정 시)

### 답변 템플릿 등록

1. 문의 상세 화면에서 **템플릿 관리** 버튼 클릭
2. **새 템플릿** 버튼 클릭
3. 템플릿 이름 입력 (예: "배송 조회 안내")
4. 템플릿 내용 작성
5. **저장** 클릭 → 이후 답변 등록 시 활용 가능

### 처리 상태 변경

| 상태 전환 | 시점 |
|-----------|------|
| 미답변 → 처리중 | 확인은 했으나 아직 처리 완료 전 |
| 처리중 → 답변완료 | 고객 질문에 답변 등록 완료 |
| 답변완료 → 완료 | 고객이 추가 문의 없이 종결 |

### 미답변 문의 일괄 확인

1. 상단 필터에서 **미답변** 선택
2. 접수된 미답변 목록 전체 조회
3. 긴급도 높은 순서(접수일 오래된 순)로 우선 처리

## 주의사항

> **답변 목표 시간**: 고객 문의는 접수 후 **24시간 이내** 답변을 목표로 하세요. 미답변 기간이 길어지면 쇼핑몰 평점에 부정적 영향을 줄 수 있습니다.

- 교환/반품 요청은 답변과 함께 실제 처리(주문 취소, 환불 등)까지 완료한 후 상태를 "완료"로 변경하세요.
- 민감한 개인정보(계좌번호, 주민번호 등)가 문의 내용에 포함된 경우 적절히 마스킹 처리 후 보관하세요.
- 악의적인 문의나 반복 민원은 **블라인드** 처리 후 내부 메모에 사유를 기록해 두세요.
- 답변 등록 후 고객이 추가 답글을 달면 다시 **미답변** 상태로 전환됩니다. 알림 설정을 통해 빠르게 확인하세요.
