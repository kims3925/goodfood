# 쿠폰

쇼핑몰 고객에게 발급하는 할인 쿠폰을 생성하고 관리하는 페이지입니다. 할인율 또는 할인 금액을 설정하고, 유효기간, 발급 조건, 사용 제한 등을 세밀하게 관리할 수 있습니다.

---

## 화면 구성

### 쿠폰 현황 요약

| 카드 | 설명 |
|------|------|
| 활성 쿠폰 | 현재 발급 가능한 쿠폰 종류 수 |
| 발급 수 | 전체 기간 발급된 쿠폰 총 수량 |
| 사용 수 | 실제 주문에 적용된 쿠폰 수량 |
| 사용률 | 발급 대비 사용 비율 (%) |

### 쿠폰 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 쿠폰 코드 | 고객이 입력하는 코드 (예: SUMMER10) |
| 쿠폰명 | 내부 관리용 쿠폰 이름 |
| 할인 유형 | 정률 할인 (%) / 정액 할인 (원) |
| 할인값 | 할인율 또는 할인 금액 |
| 최소 주문금액 | 쿠폰 사용에 필요한 최소 구매액 |
| 최대 할인금액 | 정률 쿠폰의 할인 상한선 |
| 유효기간 | 쿠폰 사용 가능 기간 |
| 발급 수량 | 설정된 총 발급 가능 수량 (무제한 포함) |
| 사용/발급 | 사용된 수량 / 발급된 수량 |
| 상태 | 활성 / 비활성 / 만료 |

## 주요 기능

### 쿠폰 종류

| 쿠폰 유형 | 설명 | 예시 |
|-----------|------|------|
| 정률 쿠폰 | 주문 금액의 N% 할인 | 10% 할인 쿠폰 |
| 정액 쿠폰 | 주문 금액에서 N원 차감 | 3,000원 할인 쿠폰 |
| 무료배송 쿠폰 | 배송비 전액 면제 | 배송비 무료 쿠폰 |
| 상품 지정 쿠폰 | 특정 상품에만 적용 | 사과즙 전용 5% 할인 |
| 카테고리 쿠폰 | 특정 카테고리에만 적용 | 수산물 카테고리 8% 할인 |
| 신규 회원 쿠폰 | 첫 구매 고객에게 자동 발급 | 첫 구매 2,000원 할인 |

### 쿠폰 발급 방식

| 발급 방식 | 설명 |
|-----------|------|
| 코드 직접 입력 | 고객이 결제 시 코드 입력 |
| 자동 발급 | 특정 조건 충족 시 자동 지급 (신규 회원, 생일 등) |
| 관리자 직접 발급 | 특정 고객에게 개별 발급 |
| 다운로드 쿠폰 | 쇼핑몰 내 쿠폰 페이지에서 다운로드 방식 |

### 쿠폰 사용 조건 설정

| 조건 | 설명 |
|------|------|
| 최소 주문금액 | 해당 금액 이상 주문 시에만 사용 가능 |
| 적용 상품 | 전체 상품 / 특정 상품 / 특정 카테고리 |
| 중복 사용 | 다른 쿠폰과 중복 적용 허용 여부 |
| 1인 사용 횟수 | 한 고객당 최대 사용 횟수 제한 |
| 신규 회원 전용 | 첫 구매 고객에게만 적용 |

## 사용 방법

### 쿠폰 생성

1. **쿠폰** 페이지에서 **쿠폰 생성** 버튼 클릭
2. 쿠폰 기본 정보 입력:
   - **쿠폰명**: 내부 관리용 이름 (예: "여름 시즌 할인")
   - **쿠폰 코드**: 고객 입력용 코드 (자동 생성 또는 직접 입력)
3. 할인 유형 선택:
   - 정률 (%) 또는 정액 (원) 선택 후 값 입력
   - 정률 쿠폰은 최대 할인 금액 설정 권장
4. 사용 조건 설정:
   - 최소 주문금액
   - 적용 상품 범위
   - 1인 사용 횟수 제한
5. 발급 수량 설정:
   - 한정 수량: 최대 발급 수량 입력
   - 무제한: 무제한 발급 선택
6. 유효기간 설정 (시작일 ~ 종료일)
7. **저장** 버튼 클릭 → 쿠폰 활성화

### 특정 고객에게 쿠폰 발급

1. 해당 쿠폰 클릭 → 상세 화면 진입
2. **개별 발급** 탭 선택
3. 고객 이메일 또는 회원 ID 입력
4. **발급** 버튼 클릭
5. 해당 고객 계정에 쿠폰 자동 지급

### 쿠폰 발급/사용 현황 조회

1. 쿠폰 목록에서 조회할 쿠폰 클릭
2. **발급 현황** 탭 선택:
   - 발급받은 고객 목록
   - 각 고객의 사용 여부 및 사용 날짜
   - 사용된 주문번호
3. **통계** 탭 선택:
   - 일별 발급 수 그래프
   - 사용률 추이

### 쿠폰 비활성화 / 삭제

1. 해당 쿠폰의 상태 토글을 **비활성**으로 변경 → 즉시 사용 불가
2. 삭제는 발급 이력이 없는 쿠폰만 가능
3. 발급 이력이 있는 쿠폰은 비활성화 후 보관 (기록 유지 목적)

## 주의사항

> **쿠폰 코드 보안**: 쿠폰 코드를 공개 채널(SNS, 오픈 단체카톡방 등)에 노출할 경우 발급 수량이 빠르게 소진될 수 있습니다. 한정 수량 설정을 반드시 확인하세요.

- 정률 쿠폰에 최대 할인 금액을 설정하지 않으면 고가 상품 주문 시 과도한 할인이 적용될 수 있습니다. 반드시 상한선을 설정하세요.
- 무료배송 쿠폰은 배송비가 별도로 계산되는 상품에만 효과가 있습니다. 이미 무료배송 상품에는 적용되지 않습니다.
- 쿠폰 유효기간 만료 3일 전에 고객에게 알림을 보내면 사용률을 높일 수 있습니다.
- 중복 사용 허용 설정 시 다른 할인 프로모션과 겹쳐 예상보다 큰 할인이 발생할 수 있으니 주의하세요.
