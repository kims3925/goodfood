# 정산 이력

과거에 완료된 정산 내역을 조회하고 분석하는 페이지입니다. 월별/분기별 매출 추이를 파악하고 세무 신고나 경영 분석에 필요한 정산 데이터를 조회하거나 내보낼 수 있습니다.

---

## 화면 구성

### 정산 이력 요약

| 카드 | 설명 |
|------|------|
| 올해 총 정산 | 현재 연도 기준 완료된 정산 금액 합계 |
| 지난달 정산 | 전월 최종 정산 금액 |
| 평균 월 정산 | 최근 6개월 월 평균 정산액 |
| 총 정산 건수 | 완료 처리된 전체 정산 건수 |

### 정산 이력 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 정산번호 | 완료된 정산의 고유 번호 |
| 정산 기간 | 해당 정산이 포함한 판매 기간 |
| 정산 완료일 | 정산이 완료(지급) 처리된 날짜 |
| 총 판매 금액 | 기간 내 총 판매액 |
| 환불 금액 | 기간 내 환불 차감액 |
| 수수료 | 결제 및 플랫폼 수수료 합계 |
| 최종 정산 금액 | 실제 지급된 정산액 |
| 처리자 | 정산 완료를 확인한 담당자 |

## 주요 기능

### 기간별 조회 및 필터

| 필터 | 옵션 |
|------|------|
| 조회 기간 | 정산 완료일 기준 날짜 범위 |
| 연도 선택 | 연도별 탭 전환 |
| 분기 선택 | 1Q / 2Q / 3Q / 4Q |
| 월별 선택 | 특정 월 단위 조회 |

### 월별 정산 추이 그래프

- 최근 12개월 정산 금액 막대 그래프
- 전년 동월 대비 증감율 표시
- 마우스 오버 시 해당 월 상세 수치 툴팁 표시

### 상품별 판매 집계 (기간 합산)

정산 이력 조회 기간 내 상품별 판매 현황을 집계합니다.

| 항목 | 설명 |
|------|------|
| 상품명 | 판매된 상품 이름 |
| 총 판매 수량 | 해당 기간 누적 판매량 |
| 총 판매 금액 | 수량 × 단가 합계 |
| 환불 수량 | 환불된 수량 |
| 순 판매 금액 | 판매 금액 - 환불 금액 |

### 세금계산서 / 영수증 조회

| 기능 | 설명 |
|------|------|
| 세금계산서 번호 | 발행된 세금계산서 번호 확인 |
| 영수증 다운로드 | PDF 형식 영수증 다운로드 |
| 공급가액 확인 | VAT 포함/별도 구분 |

## 사용 방법

### 월별 정산 이력 조회

1. **정산 이력** 페이지 접속
2. 상단 연도 탭에서 조회 연도 선택
3. 해당 연도의 월별 정산 목록 확인
4. 특정 월 정산번호 클릭 → 상세 내역 조회

### 분기별 매출 분석

1. 연도 선택 후 **분기 조회** 탭 선택
2. 1Q ~ 4Q 중 원하는 분기 선택
3. 분기 합산 판매 금액 및 정산 금액 확인
4. **엑셀 내보내기**로 분기 데이터 추출

### 정산 이력 내보내기

1. 조회할 기간 설정 (연도 또는 직접 지정)
2. 상단 **내보내기** 버튼 클릭
3. 내보내기 옵션 선택:
   - **요약본**: 정산 목록만 포함 (1행 = 1건)
   - **상세본**: 각 정산에 포함된 주문 상세까지 포함
4. 엑셀 파일 다운로드

### 세금계산서 발행 확인

1. 특정 정산 이력 클릭
2. "세금계산서" 탭 선택
3. 발행된 세금계산서 번호 및 공급가액 확인
4. PDF 다운로드 (세무 신고 시 활용)

## 주의사항

> **정산 이력은 수정 불가**: 정산 완료 처리된 이력은 변경할 수 없습니다. 오류가 있는 경우 담당 관리자에게 문의하거나 별도 조정 정산서를 생성하세요.

- 정산 이력은 최소 **5년**간 보관됩니다. 세무 신고 및 감사 목적으로 필요한 데이터는 정기적으로 백업하는 것을 권장합니다.
- VAT(부가가치세) 처리는 사업자 형태에 따라 다를 수 있습니다. 세금 신고는 반드시 세무사와 상담 후 진행하세요.
- 정산 이력과 은행 계좌 입금 내역이 맞지 않는 경우 **정산 목록** 페이지의 수수료 설정을 먼저 확인하세요.
