# BandAuto 매니저 사용 매뉴얼

## 밴드오토란?

BandAuto(밴드오토)는 **Band 기반 소셜커머스 상품 소싱 및 판매 자동화 플랫폼**입니다. 도매 밴드에서 상품을 자동 수집하고, AI가 상품을 가공하여 소매 밴드에 발행하며, 쇼핑몰 주문/정산까지 한 곳에서 관리할 수 있습니다.

## 이 매뉴얼의 대상

이 매뉴얼은 **매니저(MANAGER) 역할** 사용자를 위한 가이드입니다. 매니저는 채널 등록, 상품 소싱, AI 가공, 밴드 발행, 쇼핑몰 운영 등 플랫폼의 핵심 기능을 사용합니다.

## 플랫폼 구성

BandAuto는 크게 두 영역으로 나뉩니다:

| 영역 | 설명 |
|------|------|
| **매니저 (소싱)** | 채널 관리, 상품 소싱/가공/발행, 광고, 자동화, AI 채팅 |
| **쇼핑몰** | 쇼핑몰 관리, 상품/주문/정산, 고객 관리 |

## 접속 방법

1. 브라우저에서 **https://snsauto.abcpharm.net** 접속
2. 매니저 계정으로 로그인
3. 좌측 사이드바에서 **매니저 / 쇼핑몰** 탭 전환

## 전체 메뉴 구조

### 매니저 탭

- 대시보드
- 채널 관리
- 상품 (상품소싱 / 가공상품 / 발행)
- 광고&마케팅 (종합발행 / 콜라주 / 카톡광고 / 밴드공지)
- 자동화 (자동화 설정 / 소싱조건 설정 / 실행 로그)
- AI 채팅 (통합 인박스 / 자동응답 설정 / 운영 매뉴얼)
- 외부 연동 (외부몰 연동 / AI 페이지빌더)
- 설정 (AI/API / 프롬프트·가격정책 / 구글시트 / 알림 / 매니저 관리)

### 쇼핑몰 탭

- 대시보드
- 쇼핑몰 관리
- 상품 관리
- 주문/정산 (주문 / 라이트주문 / 발주 / 정산 / 정산이력 / 도매정산서)
- 고객관리 (고객 문의 / 리뷰 관리 / 쿠폰)
- 설정 (회원 목록 / 실시간 접속자 / 알림)
