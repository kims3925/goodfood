# 발행

가공이 완료된 상품을 소매 밴드 채널에 게시하는 메뉴입니다. 개별 발행 또는 일괄 발행을 지원하며, 발행 진행 상황과 결과를 실시간으로 확인할 수 있습니다.

![발행 화면](../.gitbook/assets/publish.png)

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 발행 대기 목록 | 발행 요청 후 처리를 기다리는 상품 목록 |
| 발행 진행 목록 | 현재 밴드에 게시 중인 상품 및 진행률 표시 |
| 발행 완료 목록 | 발행이 완료된 상품, 게시물 링크 및 결과 확인 |
| 발행 실패 목록 | 오류로 발행에 실패한 상품, 오류 원인 및 재시도 버튼 |
| 필터 및 검색 | 채널, 날짜, 상태별 조회 |

## 발행 상태

| 상태 | 설명 |
|------|------|
| **발행 대기** | 발행 요청이 접수되어 처리 순서를 기다리는 중 |
| **발행 중** | Playwright가 밴드에 게시물을 작성하고 있는 중 |
| **발행 완료** | 소매 밴드에 게시물이 성공적으로 등록된 상태 |
| **발행 실패** | 오류로 인해 발행에 실패한 상태 |

## 주요 기능

### 개별 발행
하나의 상품을 즉시 발행할 수 있습니다.

- 가공 상품 메뉴에서 발행할 상품의 **발행** 버튼을 클릭합니다.
- 또는 발행 메뉴에서 대기 중인 상품의 **즉시 발행** 버튼을 클릭합니다.
- 발행 대상 소매 밴드 채널을 선택하고 확인합니다.

### 일괄 발행
여러 상품을 한 번에 발행 요청할 수 있습니다.

- 발행할 상품을 체크박스로 다중 선택합니다.
- 상단 **일괄 발행** 버튼을 클릭합니다.
- 발행 간격(초 단위)을 설정하여 밴드 정책에 맞게 게시 속도를 조절합니다.
- 발행 순서는 드래그로 변경할 수 있습니다.

### 발행 결과 확인
- **발행 완료** 탭에서 게시물 링크를 클릭하면 밴드의 실제 게시물로 이동합니다.
- 발행일시, 채널명, 게시물 ID를 확인할 수 있습니다.

### 발행 실패 재시도
- **발행 실패** 탭에서 실패 원인 메시지를 확인합니다.
- 오류 원인을 해결한 후 **재시도** 버튼을 클릭합니다.
- 일반적인 실패 원인: 밴드 로그인 세션 만료, 채널 권한 없음, 네트워크 오류

## 사용 방법

### 기본 발행 절차

1. **가공 상품** 메뉴에서 발행할 상품을 선택합니다.
2. **발행** 버튼 클릭 후 발행 대상 소매 밴드 채널을 선택합니다.
3. 발행 메뉴의 **발행 대기** 탭에서 대기 중인 상품을 확인합니다.
4. 시스템이 자동으로 순서대로 밴드에 게시물을 작성합니다.
5. **발행 완료** 탭에서 게시물 링크로 결과를 확인합니다.

### 발행 일시 예약하기

1. 발행할 상품을 선택 후 **발행** 버튼을 클릭합니다.
2. 발행 설정 팝업에서 **예약 발행** 탭으로 전환합니다.
3. 발행 날짜와 시간을 선택합니다.
4. **예약 확인** 버튼을 클릭하면 해당 시간에 자동으로 발행됩니다.

### 발행 취소하기

1. **발행 대기** 탭에서 취소할 상품을 찾습니다.
2. 상품 우측의 **취소** 버튼을 클릭합니다.
3. 취소된 상품은 **가공 상품** 메뉴의 가공 완료 상태로 돌아갑니다.
4. 단, **발행 중** 상태에서는 취소가 불가합니다.

## 주의사항

- 밴드는 짧은 시간에 대량의 게시물을 게시하면 스팸으로 감지될 수 있습니다. 일괄 발행 시 게시물 간 간격을 최소 30초 이상으로 설정하세요.
- 발행 중 밴드 계정의 로그인 세션이 만료되면 발행이 중단됩니다. **채널 관리** 메뉴에서 채널 세션 상태를 정기적으로 확인하세요.
- 동일한 이미지와 내용의 게시물을 반복 발행하면 밴드 정책에 의해 제한될 수 있습니다.
- 발행 완료된 게시물은 밴드에서 직접 삭제하거나 수정해야 합니다. 시스템에서는 발행 후 게시물 내용을 변경할 수 없습니다.
