# 가공 상품

수집된 도매 게시물을 기반으로 Gemini AI가 소매 판매용 상품 정보를 자동 가공하는 메뉴입니다. AI가 생성한 상품명, 설명, 가격을 검토하고 편집한 뒤 소매 밴드에 발행합니다.

## 화면 구성

| 영역 | 설명 |
|------|------|
| 상태 탭 | 전체 / 가공 대기 / 가공 완료 / 발행 완료 탭으로 분류 |
| 상품 카드 목록 | 가공된 상품의 썸네일, 상품명, 소매가, 상태 배지 표시 |
| 검색 및 필터 | 채널, 날짜, 키워드, 상태로 검색 |
| 상품 편집 패널 | 상품 클릭 시 우측 패널에서 상세 정보 편집 |
| 일괄 작업 버튼 | 선택한 상품 일괄 가공 재요청, 발행, 삭제 |

## 상품 상태

| 상태 | 설명 |
|------|------|
| **가공 대기** | 가공 요청 후 AI 처리를 기다리는 상태 |
| **가공 중** | Gemini AI가 현재 상품 정보를 생성하고 있는 상태 |
| **가공 완료** | AI 가공이 완료되어 검토 및 편집 가능한 상태 |
| **발행 완료** | 소매 밴드에 게시 완료된 상태 |
| **가공 실패** | AI 처리 중 오류가 발생한 상태 (재요청 가능) |

## Gemini AI 가공 내용

가공 요청이 접수되면 Gemini AI는 원본 도매 게시물을 분석하여 다음 항목을 자동 생성합니다.

### 상품명 생성
- 도매 게시물의 원본 제목에서 상품 핵심 정보를 추출합니다.
- 소비자 친화적인 표현으로 재작성합니다.
- 검색 최적화를 위한 키워드를 자연스럽게 포함합니다.
- 예: `[도매] 제주산 하우스 감귤 5kg (당도 높음)` → `달콤한 제주 하우스 감귤 5kg 선물세트`

### 상품 설명 생성
- 원본 게시물 본문의 상품 특징, 원산지, 중량, 보관 방법 등을 파악합니다.
- 소비자가 구매를 결정하는 데 도움이 되는 구조화된 설명으로 재작성합니다.
- 이모지, 강조 문구 등을 활용하여 읽기 쉬운 형태로 작성합니다.

### 소매 가격 산정
- 도매 게시물의 공급가를 기반으로 설정된 마진율을 적용하여 소매 가격을 자동 계산합니다.
- 마진율은 **소싱조건 설정** 메뉴에서 채널별 또는 카테고리별로 설정할 수 있습니다.
- 계산된 가격은 편집 패널에서 수동으로 조정할 수 있습니다.

### 이미지 선택
- 원본 게시물의 이미지 중 가격 정보가 없는 이미지를 자동 선별합니다.
- 상품을 가장 잘 표현하는 이미지가 대표 이미지로 설정됩니다.

## 사용 방법

### 가공 상품 검토 및 편집하기

1. **가공 완료** 탭에서 검토할 상품 카드를 클릭합니다.
2. 우측 편집 패널에서 AI가 생성한 내용을 확인합니다.
3. 필요한 경우 상품명, 설명, 가격을 직접 수정합니다.
4. 이미지 순서를 드래그 앤 드롭으로 변경하거나 불필요한 이미지를 삭제합니다.
5. **저장** 버튼을 클릭하여 변경 사항을 저장합니다.

### 가공 실패 상품 재요청하기

1. 상태 탭에서 **가공 실패** 항목을 확인합니다.
2. 해당 상품 카드 우측 상단의 **재가공** 버튼을 클릭합니다.
3. 또는 여러 상품을 선택 후 상단 **일괄 재가공** 버튼을 이용합니다.

### 일괄 발행 요청하기

1. 발행할 상품의 체크박스를 선택합니다.
2. 상단 **발행** 버튼을 클릭합니다.
3. 발행 대상 소매 밴드 채널을 선택합니다.
4. **발행 확인** 버튼을 클릭하면 **발행** 메뉴에서 진행 상황을 확인할 수 있습니다.

## 주의사항

- 가공 완료 후 편집하지 않고 바로 발행하더라도 문제는 없지만, AI가 생성한 내용을 한 번 검토하는 것을 권장합니다.
- 소매 가격이 도매 가격보다 낮게 산정된 경우 **⚠️ 가격 오류** 경고가 표시됩니다. 반드시 수정 후 발행하세요.
- 가공 완료 상품은 30일 이내에 발행하지 않으면 자동으로 보관 처리됩니다.
- Gemini AI 가공은 요청당 평균 10~30초가 소요됩니다. 대량 요청 시 처리 시간이 길어질 수 있습니다.
