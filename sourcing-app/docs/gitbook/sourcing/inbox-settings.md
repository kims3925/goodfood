# AI 자동응답 설정

AI 채팅 인박스의 자동 응답 동작 방식을 설정하는 메뉴입니다. 채널별로 자동 응답 활성화 여부를 조정하고, 응답 템플릿과 예외 처리 규칙을 구성합니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 채널별 자동응답 토글 | 각 소매 밴드 채널의 AI 자동응답 ON/OFF |
| 응답 지연 설정 | 메시지 수신 후 AI 응답까지의 대기 시간 |
| 응답 템플릿 관리 | 유형별 응답 초안 템플릿 등록/편집 |
| 예외 키워드 설정 | 자동 응답하지 않고 수동 처리로 전환할 키워드 |
| 업무 시간 설정 | 자동응답이 활성화되는 시간대 설정 |
| 응답 성능 통계 | AI 자동응답 처리율, 정확도 집계 |

---

## 주요 설정 항목

### 채널별 자동응답 ON/OFF
- 등록된 소매 밴드 채널마다 AI 자동응답을 개별적으로 활성화/비활성화합니다.
- 신규 채널은 기본적으로 **비활성** 상태로 시작됩니다. 충분히 테스트한 후 활성화하세요.

### 응답 지연 시간
즉시 응답하면 AI 자동화로 보일 수 있어 고객 신뢰를 낮출 수 있습니다. 적절한 지연 시간을 설정하세요.

| 옵션 | 설명 |
|------|------|
| 즉시 (0초) | 메시지 감지 즉시 응답 |
| 30초 ~ 3분 | 자연스러운 응답 지연 (권장) |
| 사용자 지정 | 직접 초 단위로 입력 |

### 업무 시간 설정
- **업무 시간 내**: AI 자동응답 + 필요 시 수동 보완
- **업무 시간 외**: AI 자동응답만 동작하거나, 응답 대기 안내 메시지만 발송
- 업무 시간 외 자동 안내 메시지 예: `안녕하세요! 현재 업무 시간(오전 9시~오후 6시) 외입니다. 내일 오전에 답변 드리겠습니다.`

## 응답 유형 및 템플릿

AI는 고객 메시지의 의도를 분석하여 아래 유형 중 하나로 분류하고, 해당 유형의 템플릿을 기반으로 응답을 생성합니다.

| 의도 유형 | 설명 | 예시 메시지 |
|----------|------|------------|
| **상품 문의** | 상품 정보, 재고 관련 질문 | "이 감귤 아직 있나요?" |
| **가격 문의** | 가격 확인 요청 | "딸기 1kg 얼마예요?" |
| **주문 방법** | 구매 방법 문의 | "어떻게 주문해요?" |
| **배송 문의** | 배송 일정, 방법 질문 | "언제 받을 수 있어요?" |
| **주문 상태 확인** | 기존 주문 진행 상황 | "주문한 거 배송됐나요?" |
| **교환/환불** | 불만, 교환, 환불 요청 | "상품이 상해서 왔어요" |
| **기타 인사** | 인사말, 일반 메시지 | "안녕하세요" |

각 유형별로 응답 템플릿을 직접 작성하거나 AI 생성 초안을 수정하여 저장합니다.

### 템플릿 변수 사용
템플릿에서 다음 변수를 사용하면 실제 값으로 자동 치환됩니다.

| 변수 | 치환 내용 |
|------|----------|
| `{고객명}` | 밴드 프로필 이름 |
| `{상품명}` | 문의한 게시물의 상품명 |
| `{가격}` | 해당 상품의 소매 가격 |
| `{배송일}` | 예상 배송 일정 (설정값 기반) |
| `{주문방법}` | 설정된 주문 안내 문구 |
| `{전화번호}` | 운영자 연락처 |

## 예외 처리 설정

### 수동 처리 전환 키워드
아래 키워드가 고객 메시지에 포함되면 AI 자동응답 대신 **검토 필요** 상태로 전환하여 수동 응답을 요청합니다.

기본 등록 키워드: `환불`, `취소`, `항의`, `불만`, `사기`, `신고`, `소비자원`, `상해`, `이물질`

추가 키워드를 직접 입력하여 등록할 수 있습니다.

### 반복 문의 처리
- 같은 고객이 동일 내용을 반복 문의하면 응답을 건너뛰거나 특별 안내 메시지를 발송합니다.
- 반복 횟수 기준(예: 3회 이상)을 설정합니다.

### AI 신뢰도 임계값
AI가 응답을 자동 발송할 신뢰도 기준을 설정합니다.

- **높음 (90% 이상)**: 매우 확실한 경우에만 자동 발송 → 자동화율 낮지만 정확도 높음
- **중간 (70% 이상)**: 권장 설정 → 적절한 자동화율과 정확도 균형
- **낮음 (50% 이상)**: 자동화율 높지만 부적절한 응답 발생 가능성 증가

## 사용 방법

### 기본 자동응답 설정하기

1. **채널 선택** 목록에서 설정할 소매 밴드 채널을 선택합니다.
2. **자동응답 토글**을 ON으로 전환합니다.
3. **응답 지연 시간**을 설정합니다. (1~2분 권장)
4. **업무 시간**을 입력합니다.
5. **저장** 버튼을 클릭합니다.

### 응답 템플릿 설정하기

1. **응답 템플릿** 탭으로 이동합니다.
2. 설정할 의도 유형을 선택합니다. (예: 주문 방법)
3. 템플릿 본문을 작성합니다. 변수를 활용하여 개인화합니다.
4. **저장** 버튼을 클릭합니다.
5. **테스트 메시지 발송** 버튼으로 실제 동작을 확인합니다.

## 주의사항

- AI 자동응답을 처음 활성화할 때는 낮은 트래픽 시간대에 테스트하고, 응답 내용을 직접 모니터링하세요.
- 환불, 불만 등 민감한 키워드는 반드시 예외 키워드에 등록하여 수동 처리하세요.
- 응답 템플릿에 가격 정보를 하드코딩하지 말고 `{가격}` 변수를 사용하세요. 가격이 변경되어도 자동으로 반영됩니다.
- AI 자동응답은 밴드의 채팅 기능 내에서만 동작합니다. 게시물 댓글 자동 응답은 별도 기능입니다.
