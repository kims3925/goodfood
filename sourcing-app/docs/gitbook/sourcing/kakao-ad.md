# 카톡 광고

카카오톡 채널을 통해 고객에게 상품 광고 메시지를 발송하는 메뉴입니다. 상품 이미지와 구매 링크가 포함된 카카오 메시지를 채널 친구(구독자)에게 발송하여 구매를 유도합니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 광고 발송 목록 | 과거 발송된 광고 이력 (발송일, 수신자 수, 클릭률) |
| 새 광고 발송 버튼 | 광고 메시지 작성 및 발송 설정 팝업 열기 |
| 메시지 편집기 | 메시지 유형 선택, 상품 연동, 문구 작성 |
| 발송 예약 설정 | 즉시 발송 또는 예약 발송 시간 설정 |
| 채널 선택 | 발송에 사용할 카카오톡 채널 선택 |
| 통계 대시보드 | 광고 메시지 발송 수, 열람률, 클릭률 집계 |

---

## 지원 메시지 유형

| 유형 | 설명 | 적합한 용도 |
|------|------|------------|
| **단순 텍스트** | 텍스트만 포함된 기본 메시지 | 간단한 공지, 안내 |
| **이미지형** | 이미지 1장 + 텍스트 | 단일 상품 홍보 |
| **리스트형** | 여러 상품을 리스트로 나열 | 오늘의 특가 목록 |
| **피드형** | 상품 이미지 + 제목 + 버튼 카드 | 프리미엄 상품 홍보 |
| **콜라주형** | 콜라주 이미지 + 버튼 | 다수 상품 한눈에 홍보 |

## 주요 기능

### 카카오톡 채널 연동
- 카카오 비즈니스 계정과 연동된 카카오톡 채널을 시스템에 등록합니다.
- 채널 등록은 **채널 관리** 메뉴 > **카카오 채널** 탭에서 진행합니다.
- 여러 개의 카카오 채널을 등록하여 대상에 따라 선택 발송할 수 있습니다.

### 상품 자동 연동
- 가공 완료 상품을 선택하면 상품명, 이미지, 가격이 메시지에 자동으로 삽입됩니다.
- 상품 클릭 시 이동할 링크를 지정합니다 (밴드 게시물, 쇼핑몰 상품페이지 등).
- 쿠폰 코드 또는 할인 정보를 메시지에 포함할 수 있습니다.

### 발송 대상 설정
- **전체 채널 친구**: 채널을 추가한 모든 사용자에게 발송합니다.
- **타겟 발송**: 성별, 연령대, 지역 등 조건으로 대상을 필터링합니다. (카카오 비즈니스 계정 설정에 따라 지원 범위 상이)

### 발송 통계 확인
발송 후 다음 통계를 실시간으로 확인할 수 있습니다.

- **발송 수**: 실제 발송된 메시지 수
- **수신 수**: 수신자가 메시지를 받은 수
- **열람율**: 메시지를 열어본 비율
- **클릭율**: 버튼 또는 링크를 클릭한 비율
- **전환율**: 클릭 후 실제 주문이 발생한 비율 (밴드 주문 연계 시)

## 사용 방법

### 광고 메시지 발송하기

1. **새 광고 발송** 버튼을 클릭합니다.
2. **채널 선택** 드롭다운에서 발송에 사용할 카카오톡 채널을 선택합니다.
3. **메시지 유형**을 선택합니다. (이미지형, 리스트형, 피드형 등)
4. **상품 선택** 버튼으로 광고할 가공 완료 상품을 선택합니다.
5. 메시지 제목과 본문 문구를 입력합니다.
6. **버튼 설정**에서 버튼 텍스트와 이동 링크를 입력합니다.
7. 미리보기 버튼으로 최종 메시지 모습을 확인합니다.
8. **발송 시간**을 즉시 또는 예약으로 설정합니다.
9. **발송** 버튼을 클릭합니다.

### 기존 광고 재발송하기

1. 광고 발송 목록에서 재발송할 항목을 클릭합니다.
2. **복사하여 발송** 버튼을 클릭합니다.
3. 메시지 내용을 수정하고 새 발송 시간을 설정합니다.
4. **발송** 버튼을 클릭합니다.

---

## 주의사항

- 카카오톡 채널 메시지 발송은 카카오 비즈니스 계정이 필요하며, 발송 건당 비용이 발생합니다. 발송 전 카카오 비즈니스 잔액을 확인하세요.
- 스팸성 메시지나 과도한 발송은 채널 운영 정책 위반으로 채널이 제재될 수 있습니다. 하루 1~2회 이내로 발송하는 것을 권장합니다.
- 수신 동의를 하지 않은 사용자에게 광고 메시지를 발송하는 것은 정보통신망법 위반입니다. 반드시 채널 추가(수신 동의)한 사용자에게만 발송하세요.
- 발송 예약 취소는 예약 시간 10분 전까지만 가능합니다.
