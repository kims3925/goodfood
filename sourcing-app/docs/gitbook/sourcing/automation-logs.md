# 실행 로그

자동화 규칙의 실행 이력을 조회하고, 성공/실패 결과 및 오류 상세 내용을 확인하는 메뉴입니다. 시스템이 어떤 작업을 언제 수행했는지 추적하고, 오류 발생 시 원인을 파악할 수 있습니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 로그 필터 바 | 날짜 범위, 자동화 규칙, 실행 유형, 결과(성공/실패) 필터 |
| 로그 목록 | 실행 이력 목록 (실행 시간, 규칙 이름, 처리 건수, 결과) |
| 로그 상세 패널 | 선택한 로그의 상세 내용 및 오류 메시지 |
| 통계 요약 | 기간별 성공률, 처리 건수, 오류 빈도 집계 |

---

## 로그 결과 유형

| 결과 | 아이콘 | 설명 |
|------|--------|------|
| **성공** | ✅ | 모든 작업이 정상적으로 완료됨 |
| **부분 성공** | ⚠️ | 일부 항목만 성공하고 일부는 실패함 |
| **실패** | ❌ | 실행 자체가 실패하거나 모든 항목이 실패함 |
| **건너뜀** | ⏭️ | 실행 조건 미충족으로 작업을 수행하지 않음 (예: 수집할 새 게시물 없음) |
| **취소됨** | 🚫 | 사용자가 수동으로 취소한 경우 |

---

## 로그 상세 정보

각 실행 로그를 클릭하면 다음 상세 정보를 확인할 수 있습니다.

### 실행 요약
- **실행 시작 시간** / **완료 시간** / **소요 시간**
- **자동화 규칙 이름** 및 규칙 유형
- **처리 결과**: 성공 N건 / 실패 N건 / 건너뜀 N건

### 항목별 처리 결과
수집, 가공, 발행 각 단계에서 처리된 항목의 목록과 개별 결과를 표시합니다.

| 컬럼 | 내용 |
|------|------|
| 게시물/상품명 | 처리된 항목의 이름 또는 ID |
| 처리 단계 | 수집 / 가공 / 발행 |
| 결과 | 성공 / 실패 |
| 오류 메시지 | 실패 시 오류 원인 |

### 오류 메시지 분류

| 오류 코드 | 의미 | 해결 방법 |
|----------|------|----------|
| `AUTH_EXPIRED` | 밴드 로그인 세션 만료 | 채널 관리에서 세션 갱신 |
| `CHANNEL_NOT_FOUND` | 채널을 찾을 수 없음 | 채널 설정 확인 |
| `POST_LIMIT_EXCEEDED` | 밴드 게시물 한도 초과 | 발행 간격 늘리기 |
| `AI_API_ERROR` | Gemini AI API 오류 | 잠시 후 재시도 |
| `IMAGE_DOWNLOAD_FAIL` | 이미지 다운로드 실패 | 원본 게시물 이미지 확인 |
| `NETWORK_TIMEOUT` | 네트워크 연결 시간 초과 | 서버 상태 확인 |
| `DUPLICATE_POST` | 동일 게시물 중복 발행 시도 | 중복 방지 설정 확인 |

## 사용 방법

### 로그 조회하기

1. **날짜 필터**에서 조회할 기간을 선택합니다. (오늘, 이번 주, 이번 달, 직접 지정)
2. **자동화 규칙 필터**에서 특정 규칙의 로그만 볼 수 있습니다.
3. **결과 필터**에서 성공 / 실패 / 전체를 선택합니다.
4. 로그 목록에서 특정 항목을 클릭하면 우측 패널에 상세 내용이 표시됩니다.

### 오류 원인 파악 및 해결하기

1. **결과 필터**를 **실패**로 설정합니다.
2. 실패한 로그 항목을 클릭합니다.
3. 상세 패널의 **오류 메시지** 항목에서 오류 코드와 설명을 확인합니다.
4. 오류 코드에 맞는 해결 방법을 적용합니다.
5. 해결 후 해당 자동화 규칙을 수동으로 실행하거나 다음 자동 실행을 기다립니다.

### 통계 확인하기

1. 화면 상단의 **통계 요약** 카드에서 기간별 집계를 확인합니다.
2. **성공률**: 전체 실행 대비 성공 실행의 비율
3. **총 수집 건수** / **총 가공 건수** / **총 발행 건수**: 기간 내 처리 총량
4. **오류 빈도**: 어떤 오류가 가장 자주 발생하는지 확인하여 시스템 개선에 활용

### 로그 내보내기

1. 필터를 설정하여 내보낼 로그 범위를 지정합니다.
2. 상단 **내보내기** 버튼을 클릭합니다.
3. CSV 또는 Excel 형식으로 다운로드합니다.

---

## 주의사항

- 실행 로그는 최대 **180일**간 보관됩니다. 장기 보관이 필요한 경우 주기적으로 내보내기(Export)하여 별도 저장하세요.
- 로그에 기록된 오류가 반복적으로 발생하는 경우 자동화 설정을 재검토하거나 고객 지원팀에 문의하세요.
- 대량의 로그가 쌓이면 조회 속도가 느려질 수 있습니다. 불필요한 로그는 주기적으로 삭제(관리자 기능)하세요.
- 로그는 읽기 전용입니다. 삭제를 제외한 수정은 불가합니다.
