# AI 페이지빌더

AI를 활용하여 쇼핑몰 상품 상세 페이지, 이벤트 페이지, 브랜드 소개 페이지 등을 자동으로 생성하는 메뉴입니다. 디자인 지식 없이도 전문적인 페이지를 빠르게 제작할 수 있습니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 페이지 목록 | 생성된 페이지 목록 (유형, 제목, 생성일, 상태) |
| 새 페이지 만들기 버튼 | 페이지 생성 마법사 열기 |
| 페이지 편집기 | 블록 기반 드래그 앤 드롭 편집기 |
| AI 생성 버튼 | 상품 정보 기반 AI 자동 콘텐츠 생성 |
| 미리보기 | 모바일/PC 모드 실시간 미리보기 |
| 발행 및 링크 | 페이지를 발행하고 공유 링크 확인 |

---

## 생성 가능한 페이지 유형

| 유형 | 설명 | 주요 활용 |
|------|------|----------|
| **상품 상세 페이지** | 단일 상품의 상세 소개 페이지 | 프리미엄 상품 상세 설명 |
| **이벤트/기획전 페이지** | 시즌 행사, 할인 이벤트 페이지 | 명절 선물세트, 특가 행사 |
| **브랜드/스토어 소개 페이지** | 판매자 소개, 스토어 정보 페이지 | 신뢰 형성, 단골 유도 |
| **주문 안내 페이지** | 주문 방법, 결제, 배송 안내 | 신규 고객 주문 유도 |
| **후기 모음 페이지** | 구매 고객 후기를 모은 신뢰 페이지 | 구매 전환율 향상 |

---

## 주요 기능

### AI 자동 콘텐츠 생성
- 가공 완료 상품을 선택하면 상품 정보(이름, 설명, 이미지, 가격)를 기반으로 Gemini AI가 페이지 전체 콘텐츠를 자동으로 생성합니다.
- **생성 항목**: 헤드라인 카피, 상품 특징 소개 섹션, 구성 안내, 주문 방법, 배송 안내, CTA(Call to Action) 버튼 문구

### 블록 기반 편집기
드래그 앤 드롭으로 페이지 구성 요소를 자유롭게 배치합니다.

| 블록 유형 | 설명 |
|----------|------|
| **히어로 배너** | 상단 대형 이미지 + 제목 + 서브 텍스트 + 버튼 |
| **이미지 갤러리** | 2~4열 이미지 그리드 |
| **특징 목록** | 아이콘 + 제목 + 설명 카드 목록 |
| **텍스트 섹션** | 헤드라인 + 본문 텍스트 |
| **가격 및 주문** | 가격 표시 + 주문 방법 버튼 |
| **후기 섹션** | 고객 후기 카드 슬라이더 |
| **배송 안내** | 배송 정보 테이블 |
| **구분선 / 여백** | 레이아웃 구분 요소 |

### 디자인 테마 선택
미리 준비된 디자인 테마를 선택하면 색상, 폰트, 레이아웃이 일괄 적용됩니다.

| 테마 | 특징 |
|------|------|
| 클린 화이트 | 밝고 깔끔한 기본 디자인 |
| 신선 그린 | 친환경, 신선식품에 적합 |
| 프리미엄 다크 | 고급스러운 어두운 배경 |
| 따뜻한 오렌지 | 식품, 식재료에 어울리는 따뜻한 톤 |
| 바다 블루 | 수산물, 해산물에 적합 |

### 모바일 최적화
- 모든 페이지는 모바일 우선(Mobile First)으로 제작됩니다.
- 미리보기 화면에서 모바일/PC 모드를 전환하며 결과를 확인하세요.

### 페이지 발행 및 공유
- 작성된 페이지는 BandAuto 서버에 발행되어 고유 URL이 생성됩니다.
- 생성된 URL을 밴드 게시물, 카카오톡 메시지 등에 링크로 삽입합니다.
- QR코드 자동 생성으로 오프라인 판촉물에도 활용할 수 있습니다.

## 사용 방법

### AI로 상품 상세 페이지 자동 생성하기

1. **새 페이지 만들기** 버튼을 클릭합니다.
2. 페이지 유형을 **상품 상세 페이지**로 선택합니다.
3. **상품 선택** 버튼으로 가공 완료 상품 중 하나를 선택합니다.
4. **디자인 테마**를 선택합니다.
5. **AI 페이지 생성** 버튼을 클릭합니다. (약 15~30초 소요)
6. AI가 생성한 페이지를 편집기에서 검토합니다.
7. 수정이 필요한 블록을 클릭하여 텍스트, 이미지를 편집합니다.
8. 모바일 미리보기로 최종 확인합니다.
9. **발행** 버튼을 클릭하면 URL이 생성됩니다.
10. 생성된 URL을 밴드 게시물이나 카카오 메시지에 삽입합니다.

### 이벤트 페이지 직접 만들기

1. **새 페이지 만들기** 버튼을 클릭합니다.
2. 페이지 유형을 **이벤트/기획전 페이지**로 선택합니다.
3. 빈 편집기가 열리면 좌측 블록 목록에서 원하는 블록을 드래그하여 추가합니다.
4. 각 블록을 클릭하여 콘텐츠를 채웁니다.
5. **AI 문구 제안** 버튼으로 특정 블록의 텍스트를 AI로 자동 작성할 수 있습니다.
6. 완성 후 **발행** 버튼을 클릭합니다.

## 주의사항

- 생성된 페이지 URL은 BandAuto 구독이 활성 상태인 동안에만 접근 가능합니다. 구독이 만료되면 페이지가 비공개 처리됩니다.
- 페이지에 포함된 이미지는 BandAuto 서버에 저장됩니다. 저작권이 있는 이미지 사용 시 주의하세요.
- AI가 생성한 문구는 반드시 검토하여 사실과 다른 내용이 없는지 확인하세요. 특히 가격, 배송 정보는 정확한지 확인이 필요합니다.
- 페이지 삭제 시 해당 URL이 바로 비활성화되므로, 밴드 게시물 등에 삽입된 링크가 끊어지지 않도록 주의하세요.
