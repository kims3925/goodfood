# 콜라주 광고

여러 상품의 이미지를 하나의 광고용 콜라주 이미지로 합성하는 기능입니다. 시선을 끄는 광고 이미지를 자동으로 생성하여 밴드 게시물이나 카카오톡 광고에 활용할 수 있습니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 콜라주 목록 | 생성된 콜라주 이미지 목록 (썸네일, 제목, 포함 상품 수, 생성일) |
| 새 콜라주 버튼 | 콜라주 생성 편집기 열기 |
| 편집기 | 상품 이미지 선택, 레이아웃 지정, 텍스트 추가 |
| 미리보기 | 실시간 콜라주 이미지 미리보기 |
| 다운로드 / 발행 | 생성된 이미지 저장 또는 바로 발행 |

---

## 콜라주 레이아웃 종류

| 레이아웃 | 설명 | 권장 상품 수 |
|---------|------|------------|
| 2분할 (좌우) | 2개 이미지를 좌우로 배치 | 2개 |
| 2분할 (상하) | 2개 이미지를 상하로 배치 | 2개 |
| 3분할 | 1개 큰 이미지 + 2개 작은 이미지 | 3개 |
| 4격자 | 2×2 균등 격자 배치 | 4개 |
| 5격자 | 1개 큰 이미지 + 4개 작은 이미지 | 5개 |
| 6격자 | 2×3 균등 격자 배치 | 6개 |
| 자유 배치 | 이미지 크기와 위치를 자유롭게 설정 | 2~9개 |

## 주요 기능

### 이미지 자동 선택
- 가공 완료 상품 목록에서 콜라주에 포함할 상품을 선택하면 대표 이미지가 자동으로 불러와집니다.
- 상품별로 여러 이미지가 있는 경우 원하는 이미지를 직접 선택할 수 있습니다.

### 텍스트 오버레이
- 콜라주 이미지 위에 텍스트를 추가할 수 있습니다.
- **제목 텍스트**: 폰트, 크기, 색상, 배경 박스 유무를 설정합니다.
- **가격 텍스트**: 각 상품 이미지 영역에 가격을 자동 표시할 수 있습니다.
- **배너 문구**: 상단/하단에 `오늘만 특가`, `무료배송` 등 배너를 추가합니다.

### 배경 및 테두리 설정
- 콜라주 전체 배경색 또는 배경 패턴을 설정합니다.
- 이미지 간 간격(여백) 크기와 색상을 지정합니다.
- 이미지 모서리 둥글기(라운드)를 설정합니다.

### 출력 크기 설정
- **정사각형 (1:1)**: 1080×1080px, 밴드 피드 및 인스타그램 적합
- **세로형 (4:5)**: 1080×1350px, 모바일 피드 최적화
- **가로형 (16:9)**: 1920×1080px, 카카오톡 채널 배너 적합
- **사용자 지정**: 직접 가로×세로 픽셀 입력

## 사용 방법

### 콜라주 이미지 만들기

1. **새 콜라주** 버튼을 클릭하여 편집기를 엽니다.
2. **상품 선택** 영역에서 포함할 가공 완료 상품을 클릭합니다. (선택된 상품은 파란색 테두리로 표시)
3. **레이아웃** 탭에서 원하는 콜라주 형태를 선택합니다.
4. 각 이미지 영역을 클릭하여 어느 상품 이미지를 배치할지 지정합니다.
5. **텍스트** 탭에서 제목, 가격, 배너 문구를 입력합니다.
6. **스타일** 탭에서 배경색, 여백, 테두리를 설정합니다.
7. 우측 **미리보기** 패널에서 최종 이미지를 확인합니다.
8. 결과물 저장 또는 발행을 선택합니다.
   - **다운로드**: PNG 또는 JPEG 파일로 저장합니다.
   - **발행**: 생성된 이미지를 포함한 밴드 게시물을 바로 발행합니다.
   - **카톡 광고에 사용**: 카카오톡 광고 메뉴로 이미지를 전달합니다.

### 기존 콜라주 수정하기

1. 콜라주 목록에서 수정할 항목을 클릭합니다.
2. **편집** 버튼을 클릭하면 원본 설정이 유지된 편집기가 열립니다.
3. 수정 후 **저장**을 클릭합니다. (기존 이미지 덮어쓰기 또는 새 콜라주로 저장 선택)

## 활용 팁

- **시즌별 콜라주 템플릿**을 저장해 두면 명절, 할인 이벤트 시 빠르게 활용할 수 있습니다.
- 상품 이미지 배경이 흰색이면 여백 색을 밝은 색으로, 배경이 어두우면 어두운 여백 색을 선택하면 통일감이 높아집니다.
- 텍스트가 너무 많으면 시각적으로 복잡해집니다. 핵심 문구 1~2개만 사용하세요.

## 주의사항

- 콜라주 이미지 생성은 서버에서 처리되며 이미지 수와 크기에 따라 5~20초가 소요될 수 있습니다.
- 생성된 콜라주 이미지는 최대 90일간 시스템에 보관됩니다.
- 저작권 있는 폰트나 이미지를 사용하는 경우 반드시 라이선스를 확인하세요.
