# 종합 발행 (다이제스트)

여러 상품을 하나의 게시물에 묶어 발행하는 다이제스트 형식의 발행 메뉴입니다. 오늘의 추천 상품, 특가 모음, 카테고리별 상품 묶음 등 다양한 형태로 활용할 수 있습니다.

## 화면 구성

| 영역 | 설명 |
|------|------|
| 다이제스트 목록 | 생성된 다이제스트 목록 (제목, 포함 상품 수, 상태, 생성일) |
| 새 다이제스트 버튼 | 새 다이제스트 생성 팝업 열기 |
| 상품 선택 패널 | 가공 완료 상품 중 다이제스트에 포함할 상품 선택 |
| 미리보기 패널 | 게시물 발행 전 최종 모습 미리보기 |
| 발행 상태 | 다이제스트별 발행 대기 / 발행 중 / 발행 완료 상태 표시 |

---

## 다이제스트란?

다이제스트는 여러 상품을 하나의 밴드 게시물로 묶어 발행하는 기능입니다.

**일반 발행과의 차이점:**

| 구분 | 일반 발행 | 다이제스트 발행 |
|------|-----------|----------------|
| 게시물 수 | 상품 1개당 게시물 1개 | 여러 상품이 게시물 1개 |
| 구성 | 단일 상품 상세 정보 | 상품 요약 + 가격 목록 형태 |
| 적합한 용도 | 단일 상품 집중 홍보 | 오늘의 추천, 특가 모음 |
| 발행 빈도 | 상품마다 개별 | 하루 1~2회 종합 |

---

## 주요 기능

### 다이제스트 구성 방식

**자동 구성**: 설정한 조건(카테고리, 가격대, 채널)에 맞는 가공 완료 상품을 자동으로 선택하여 다이제스트를 생성합니다.

**수동 구성**: 가공 완료 상품 목록에서 포함할 상품을 직접 선택하고 순서를 지정합니다.

### 게시물 형식 설정
- **제목 형식**: `[오늘의 추천] 신선식품 특가 모음 N종` 등 템플릿 지정 가능
- **상품 표시 형식**: 이미지+간략 설명 / 텍스트만 / 가격표 형식 선택
- **대표 이미지**: 첫 번째 상품 이미지 또는 콜라주 이미지 사용 선택
- **주문 방법 안내**: 게시물 하단에 공통 주문 안내 문구 자동 추가

### 템플릿 관리
자주 사용하는 다이제스트 형식을 템플릿으로 저장하여 재사용할 수 있습니다.

---

## 사용 방법

### 다이제스트 직접 만들기

1. **새 다이제스트** 버튼을 클릭합니다.
2. 다이제스트 제목을 입력합니다. (예: 오늘의 신선식품 특가)
3. **상품 선택** 탭에서 포함할 가공 완료 상품을 선택합니다. (최대 20개)
4. 선택한 상품의 순서를 드래그로 조정합니다.
5. **형식 설정** 탭에서 게시물 레이아웃과 공통 안내 문구를 설정합니다.
6. **미리보기** 버튼으로 최종 게시물 모습을 확인합니다.
7. **발행** 버튼을 클릭하고 대상 소매 밴드 채널을 선택합니다.
8. **발행 확인**을 클릭하여 발행을 시작합니다.

### 자동 다이제스트 설정하기

1. **자동화 설정** 메뉴로 이동합니다.
2. **다이제스트 자동 발행** 항목을 활성화합니다.
3. 발행 주기(매일, 특정 요일)와 발행 시간을 설정합니다.
4. 자동 포함 조건(카테고리, 가격대, 최소/최대 상품 수)을 설정합니다.
5. 저장하면 설정한 시간에 자동으로 다이제스트가 생성되어 발행됩니다.

### 발행된 다이제스트 확인하기

1. 다이제스트 목록에서 **발행 완료** 항목을 클릭합니다.
2. **게시물 보기** 링크를 클릭하면 밴드의 실제 게시물로 이동합니다.
3. 해당 다이제스트에서 발생한 주문 연계 현황을 확인할 수 있습니다.

---

## 주의사항

- 하나의 다이제스트에 너무 많은 상품(20개 이상)을 포함하면 게시물이 지나치게 길어져 가독성이 떨어질 수 있습니다. 5~10개를 권장합니다.
- 다이제스트에 포함된 개별 상품을 별도로 단독 발행하면 중복 노출이 발생합니다. 발행 방식을 일관되게 유지하세요.
- 이미 발행된 다이제스트는 내용을 수정할 수 없습니다. 밴드 앱에서 직접 수정하거나 새 다이제스트를 생성하세요.
- 자동 다이제스트 생성 시 가공 완료 상품이 부족하면 발행이 건너뜁니다. 최소 상품 수를 충분히 확보하세요.
