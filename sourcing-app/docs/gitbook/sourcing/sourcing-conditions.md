# 소싱조건 설정

도매 채널에서 어떤 게시물을 수집할지 결정하는 필터 조건을 설정하는 메뉴입니다. 조건을 정밀하게 설정할수록 불필요한 게시물 수집을 줄이고 실제 판매 가능한 상품만 효율적으로 소싱할 수 있습니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 조건 세트 목록 | 저장된 소싱 조건 세트 목록 (이름, 적용 채널, 활성 상태) |
| 새 조건 만들기 버튼 | 조건 세트 생성 팝업 열기 |
| 조건 편집 패널 | 선택한 조건 세트의 상세 필터 설정 |
| 채널 연결 | 해당 조건을 적용할 도매 채널 선택 |
| 테스트 실행 | 현재 설정으로 수집 테스트 (실제 저장 없이 결과 미리보기) |

---

## 필터 조건 항목

### 키워드 조건

| 항목 | 설명 | 예시 |
|------|------|------|
| **포함 키워드** | 이 단어 중 하나라도 포함된 게시물만 수집 | 감귤, 딸기, 사과 |
| **필수 포함 키워드** | 이 단어가 반드시 모두 포함되어야 수집 | 산지직송, 무농약 |
| **제외 키워드** | 이 단어가 포함된 게시물은 수집하지 않음 | 반품불가, 배송불가, 조각 |
| **제목 전용 검색** | 키워드 검색 범위를 게시물 제목으로만 제한 | ON/OFF 설정 |

### 가격 조건

| 항목 | 설명 |
|------|------|
| **최소 도매가** | 이 금액 미만의 상품은 수집하지 않음 (저단가 제품 제외) |
| **최대 도매가** | 이 금액 초과의 상품은 수집하지 않음 (고단가 제품 제외) |
| **가격 인식 방식** | 게시물 본문에서 가격 텍스트를 인식하는 방식 설정 |

### 이미지 조건

| 항목 | 설명 |
|------|------|
| **최소 이미지 수** | 이미지가 N장 미만인 게시물은 수집하지 않음 |
| **이미지 필수** | 이미지가 없는 텍스트 전용 게시물 제외 |
| **가격 이미지 자동 제외** | 가격 정보가 포함된 이미지를 자동으로 제외 |

### 게시물 조건

| 항목 | 설명 |
|------|------|
| **게시물 작성일** | N일 이내에 작성된 게시물만 수집 |
| **최소 게시물 길이** | 본문이 N자 미만인 게시물 제외 (부실 설명 제외) |
| **중복 게시물 제외** | 동일 내용의 게시물 중복 수집 방지 |
| **공지 게시물 제외** | 채널 공지로 지정된 게시물 제외 |

### 카테고리 조건
AI가 게시물 내용을 분석하여 카테고리를 자동 분류합니다.

| 카테고리 예시 | 설명 |
|------------|------|
| 신선식품 / 채소 / 과일 | 농산물 |
| 수산물 / 건어물 | 해산물 |
| 가공식품 / 반찬 | 식품 가공 |
| 생활용품 / 주방용품 | 비식품 |

원하는 카테고리만 체크하면 해당 카테고리로 분류된 게시물만 수집합니다.

---

## 마진율 설정

소싱 조건별로 소매 가격 산정 마진율을 다르게 설정할 수 있습니다.

| 항목 | 설명 |
|------|------|
| **기본 마진율** | 도매가에 곱하는 기본 마진율 (예: 1.3 = 30% 마진) |
| **카테고리별 마진율** | 카테고리에 따라 다른 마진율 적용 |
| **최소 마진 금액** | 마진율 계산 결과 마진이 N원 미만이면 자동 보정 |
| **가격 반올림** | 소매 가격을 100원, 500원, 1000원 단위로 반올림 |

## 사용 방법

### 소싱 조건 세트 만들기

1. **새 조건 만들기** 버튼을 클릭합니다.
2. 조건 세트 **이름**을 입력합니다. (예: 신선식품 조건, 수산물 프리미엄)
3. **채널 연결** 탭에서 이 조건을 적용할 도매 채널을 선택합니다.
4. **키워드** 탭에서 포함/제외 키워드를 설정합니다.
5. **가격** 탭에서 수집할 가격 범위를 설정합니다.
6. **이미지** 탭에서 이미지 관련 조건을 설정합니다.
7. **마진** 탭에서 소매 가격 산정 마진율을 설정합니다.
8. **테스트 실행** 버튼으로 현재 조건으로 수집될 게시물을 미리 확인합니다.
9. 결과가 만족스러우면 **저장** 버튼을 클릭합니다.

### 조건 테스트하기

1. 조건 세트를 편집 중인 상태에서 **테스트 실행** 버튼을 클릭합니다.
2. 지정한 채널에서 최근 게시물을 조건에 맞게 필터링한 결과를 보여줍니다.
3. 수집될 게시물과 제외될 게시물을 각각 확인합니다.
4. 조건을 조정하며 테스트를 반복합니다.

---

## 주의사항

- 포함 키워드를 너무 많이 설정하거나 조건이 너무 느슨하면 무관한 게시물이 대거 수집될 수 있습니다. 테스트 실행으로 결과를 반드시 확인하세요.
- 제외 키워드에 `판매중단`, `품절`, `마감` 등을 추가하면 이미 재고가 없는 상품을 소싱하는 것을 방지할 수 있습니다.
- 하나의 채널에 여러 조건 세트를 동시에 적용하면 조건들이 OR 방식(어느 하나라도 만족하면 수집)으로 동작합니다.
- 마진율 설정이 너무 낮으면 실질 수익이 없거나 마이너스가 될 수 있습니다. 배송비, 플랫폼 수수료 등 추가 비용을 반드시 고려하세요.
