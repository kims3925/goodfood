# 대시보드

대시보드는 로그인 후 가장 먼저 보이는 화면으로, 플랫폼의 전체 현황을 한눈에 파악할 수 있습니다.

![대시보드 화면](../.gitbook/assets/dashboard.png)

## 화면 구성

### 상단 요약 바

화면 최상단에 실시간 파이프라인 현황이 표시됩니다:

| 항목 | 설명 |
|------|------|
| **수집** | 도매 채널에서 수집 대기 중인 게시글 수 |
| **AI 대기** | AI 가공 대기 중인 상품 수 |
| **업로드 준비** | 가공 완료 후 발행 대기 중인 상품 수 |
| **발행 완료** | 소매 밴드에 발행 완료된 상품 수 |

### 채널 현황

기간별(오늘/7일/30일/직접선택) 도매·소매 채널의 수집 및 발행 현황을 확인합니다.

- **도매 채널**: 등록된 도매 밴드 목록과 수집 건수
- **소매 채널**: 등록된 소매 밴드 목록과 발행 건수

### 수동 실행

파이프라인의 각 단계를 수동으로 실행할 수 있는 버튼입니다:

| 버튼 | 기능 |
|------|------|
| **게시물 수집** | 도매채널 게시물 즉시 수집 |
| **AI 변환** | 수집된 상품을 AI로 가공 |
| **상품 등록** | 가공 상품을 Product로 생성 |
| **발행** | 소매밴드에 상품 발행 |
| **전체 실행** | 위 4단계를 순차적으로 전체 실행 |

### 자동화 상태

현재 자동화 설정 상태를 표시합니다:
- 활성/비활성 상태
- 다음 실행 예정 시간
- 실행 주기 (예: 3회/일)

### 오늘 시간대별 처리량

시간대별 수집/변환/등록/발행/예약 처리량을 차트로 보여줍니다.

### 최근 실행 기록

최근 자동화 실행 기록을 시간순으로 보여줍니다. 각 기록에는 성공/실패 상태가 표시되며, **전체보기**를 클릭하면 실행 로그 페이지로 이동합니다.

## 기간 필터

상단의 기간 탭으로 조회 기간을 변경할 수 있습니다:
- **오늘**: 당일 데이터만 표시
- **7일**: 최근 7일간 데이터
- **30일**: 최근 30일간 데이터
- **직접선택**: 원하는 기간을 직접 지정
