# 밴드 공지

소매 밴드 채널에 공지 게시물을 작성하고 발행하는 메뉴입니다. 운영 안내, 배송 공지, 이벤트 안내 등 상품 게시물이 아닌 공지성 콘텐츠를 관리합니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 공지 목록 | 작성된 공지 목록 (제목, 대상 채널, 발행일, 상태) |
| 새 공지 작성 버튼 | 공지 작성 에디터 열기 |
| 템플릿 선택 | 자주 쓰는 공지 유형을 템플릿으로 불러오기 |
| 채널 선택 | 공지를 발행할 소매 밴드 채널 선택 (다중 선택 가능) |
| 발행 예약 | 즉시 발행 또는 날짜/시간 예약 발행 |

---

## 공지 유형

| 유형 | 설명 | 주요 내용 |
|------|------|----------|
| **일반 공지** | 운영 관련 일반 안내 | 운영 시간, 연락처, 변경 사항 |
| **배송 공지** | 배송 관련 안내 | 마감 시간, 산지 직송, 지연 안내 |
| **이벤트 공지** | 할인, 증정 이벤트 | 기간, 조건, 참여 방법 |
| **상품 입고 공지** | 신상품 또는 재입고 안내 | 상품명, 수량, 주문 방법 |
| **휴무 공지** | 공휴일, 연휴 운영 안내 | 휴무일, 재개 일정 |
| **주문 마감 공지** | 공동구매 마감 임박 안내 | 마감 시간, 잔여 수량 |

## 주요 기능

### 에디터 기능
- **텍스트 서식**: 굵게, 기울기, 밑줄, 글자 색상
- **이미지 첨부**: 최대 10장의 이미지를 본문에 포함
- **링크 삽입**: 상품 게시물 링크, 외부 URL 삽입
- **이모지 지원**: 밴드에서 지원하는 이모지를 삽입

### 다중 채널 동시 발행
- 여러 소매 밴드 채널을 동시에 선택하여 동일한 공지를 한 번에 발행합니다.
- 채널별로 공지 내용을 다르게 설정하려면 각 채널에 개별 공지를 작성합니다.

### 공지 고정 기능
- 발행 시 밴드의 **공지 고정** 옵션을 활성화할 수 있습니다.
- 고정 공지는 밴드 상단에 항상 표시됩니다.
- 기존 고정 공지가 있는 경우, 새 공지로 교체할지 또는 추가 고정할지 선택합니다.

### 템플릿 저장 및 불러오기
- 자주 반복되는 공지 형식을 템플릿으로 저장합니다.
- 새 공지 작성 시 저장된 템플릿을 불러와 내용만 수정하면 빠르게 작성할 수 있습니다.

## 사용 방법

### 공지 작성 및 발행하기

1. **새 공지 작성** 버튼을 클릭합니다.
2. **채널 선택** 목록에서 공지를 발행할 소매 밴드 채널을 선택합니다. (복수 선택 가능)
3. **공지 유형**을 선택하거나 저장된 **템플릿**을 불러옵니다.
4. 에디터에서 공지 제목과 본문을 작성합니다.
5. 필요한 경우 이미지를 첨부합니다.
6. **공지 고정** 옵션 여부를 설정합니다.
7. 발행 시간을 **즉시 발행** 또는 **예약 발행**으로 설정합니다.
8. **발행** 버튼을 클릭합니다.

### 발행된 공지 관리하기

1. 공지 목록에서 **발행 완료** 상태의 공지를 클릭합니다.
2. **게시물 보기** 링크로 밴드의 실제 게시물을 확인합니다.
3. 내용 수정이 필요한 경우 밴드 앱에서 직접 수정합니다.
4. 공지를 삭제하려면 밴드 앱에서 직접 삭제합니다. (시스템에서는 이력만 삭제됨)

### 배송 마감 공지 예약 설정하기

공동구매 마감 공지처럼 정기적으로 반복되는 공지는 예약 발행을 활용하세요.

1. 배송 마감 안내 공지를 작성합니다.
2. **예약 발행**을 선택하고 마감 전날 오후 6시 등 원하는 시간을 지정합니다.
3. **반복 발행** 옵션을 활성화하고 반복 주기(매주 특정 요일 등)를 설정합니다.
4. 저장하면 설정한 주기마다 자동으로 공지가 발행됩니다.

---

## 주의사항

- 고정 공지를 지나치게 자주 교체하면 회원들이 중요한 공지를 놓칠 수 있습니다. 핵심 운영 공지는 장기간 고정으로 유지하세요.
- 공지 발행 후 내용 수정은 밴드 앱에서 직접 해야 하며, 시스템에서는 수정 내용이 밴드에 반영되지 않습니다.
- 중요도가 낮은 공지를 과도하게 발행하면 회원들이 알림 피로를 느껴 채널을 탈퇴할 수 있습니다. 주 1~3회 이내를 권장합니다.
- 예약 공지 취소는 예약 시간 5분 전까지 가능합니다.
