# 외부몰 연동

네이버 스마트스토어 등 외부 쇼핑몰과 BandAuto를 연동하여 상품 등록, 재고 관리, 주문 수집을 통합 처리하는 메뉴입니다.

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 연동 채널 목록 | 등록된 외부몰 연동 계정 목록 (몰 유형, 계정명, 연동 상태) |
| 새 연동 추가 버튼 | 외부몰 연동 설정 마법사 열기 |
| 연동 상태 확인 | 각 외부몰 연동의 활성 상태 및 마지막 동기화 시간 |
| 상품 매핑 설정 | BandAuto 상품과 외부몰 상품 간 연결 관계 관리 |
| 주문 연동 현황 | 외부몰에서 수집된 주문 목록 및 처리 상태 |

## 주요 기능

### 상품 연동 등록
BandAuto에서 가공 완료된 상품을 외부몰에 자동으로 등록합니다.

- 상품명, 상세 설명, 가격, 이미지를 외부몰 형식에 맞게 자동 변환하여 등록합니다.
- 외부몰별 필수 항목(배송비, 원산지 등)을 추가 설정합니다.
- 등록 결과(성공/실패)와 외부몰 상품 ID를 기록합니다.

### 주문 수집 및 통합 관리
외부몰에서 발생한 주문을 BandAuto 주문 관리 시스템으로 수집합니다.

- 주기적으로 외부몰 주문 데이터를 자동 수집합니다. (기본: 15분 주기)
- 수집된 주문은 쇼핑몰 앱의 **주문 관리** 메뉴에서 밴드 주문과 통합하여 확인합니다.
- 주문 상태 변경(발송 처리 등)을 외부몰에 자동으로 반영합니다.

### 재고 동기화
- BandAuto에서 상품 품절 처리 시 외부몰 상품을 자동으로 판매 중지합니다.
- 외부몰에서 상품이 품절되면 BandAuto 상품 상태를 자동으로 업데이트합니다.

## 네이버 스마트스토어 연동 설정

네이버 스마트스토어와의 연동은 네이버 커머스 API를 통해 이루어집니다.

### 사전 준비
- 네이버 스마트스토어 계정 (판매자 계정)
- 네이버 개발자 센터에서 API 앱 등록 및 Client ID / Client Secret 발급
- 스마트스토어 API 권한 설정 (상품, 주문, 배송 권한 필요)

### 연동 설정 순서

1. **새 연동 추가** 버튼을 클릭합니다.
2. 외부몰 유형에서 **네이버 스마트스토어**를 선택합니다.
3. **네이버 개발자 센터**에서 발급받은 `Client ID`와 `Client Secret`을 입력합니다.
4. **연결 테스트** 버튼을 클릭하여 API 인증이 정상인지 확인합니다.
5. 스마트스토어에서 사용할 **배송비 정책**, **반품 정책**을 설정합니다.
6. **저장** 버튼을 클릭합니다.

### 스마트스토어 상품 등록하기

1. 가공 상품 목록에서 외부몰에 등록할 상품을 선택합니다.
2. **외부몰 등록** 버튼을 클릭합니다.
3. **네이버 스마트스토어**를 대상 몰로 선택합니다.
4. 스마트스토어 전용 추가 정보(카테고리, 원산지, 제조사 등)를 입력합니다.
5. **등록 실행** 버튼을 클릭합니다.
6. 등록 완료 후 스마트스토어 상품 URL을 확인합니다.

## 상품 매핑 관리

BandAuto 상품과 외부몰 상품이 올바르게 연결되어 있어야 주문 수집 및 재고 동기화가 정상 동작합니다.

| 항목 | 설명 |
|------|------|
| **자동 매핑** | 상품 등록 시 자동으로 외부몰 상품 ID와 연결 |
| **수동 매핑** | 기존에 등록된 외부몰 상품을 BandAuto 상품과 수동으로 연결 |
| **매핑 해제** | 연결 관계를 해제하여 동기화 중단 |

---

## 주의사항

- 외부몰 API 키는 외부에 노출되면 악용될 수 있습니다. 설정 화면에서 API 키는 마스킹 처리되며, 시스템 외부로 노출되지 않습니다.
- 외부몰의 상품 정책(금지 상품, 카테고리 규칙 등)을 반드시 사전 확인하세요. 정책 위반 시 외부몰 계정이 제재될 수 있습니다.
- 네이버 스마트스토어의 경우 상품 등록 시 별도의 심사가 필요할 수 있으며, 심사 중에는 상품이 노출되지 않습니다.
- 외부몰 API 정책 변경으로 연동이 중단될 수 있습니다. 주기적으로 연동 상태를 확인하세요.
- 외부몰 주문과 밴드 주문의 배송 처리는 각각 독립적으로 관리됩니다. 중복 발송이 발생하지 않도록 주의하세요.
