# 채널 관리

채널은 BandAuto의 핵심 단위입니다. **도매 채널**(상품을 수집하는 밴드)과 **소매 채널**(상품을 발행하는 밴드)을 등록하고 관리합니다.

![채널 관리 화면](../.gitbook/assets/channel-list.png)

## 채널 목록

등록된 모든 채널을 카드 형태로 보여줍니다. 각 카드에는 다음 정보가 표시됩니다:

- 채널명
- 채널 유형 (도매 / 소매)
- Band URL
- 세션 상태 (유효 / 만료 / 없음)
- 등록일

## 채널 등록

### 도매 채널 등록

1. **채널 추가** 버튼 클릭
2. 채널 유형: **도매** 선택
3. 채널명 입력 (예: "가족함께수산")
4. Band URL 입력 (예: `https://band.us/band/12345678`)
5. **저장** 클릭

### 소매 채널 등록

1. **채널 추가** 버튼 클릭
2. 채널 유형: **소매** 선택
3. 채널명 입력 (예: "우리동네 수산물")
4. Band URL 입력
5. **저장** 클릭

## Band 세션 관리

소매 채널에 상품을 발행하려면 **Band 세션 쿠키**가 필요합니다.

### 세션 상태

| 상태 | 설명 |
|------|------|
| 🟢 **유효** | 세션이 정상적으로 작동 중 |
| 🟡 **만료 임박** | 세션이 곧 만료됩니다. 갱신이 필요합니다 |
| 🔴 **만료 / 없음** | 세션이 없거나 만료되었습니다. 발행이 불가합니다 |

### 세션 갱신 방법

1. Chrome에서 **Band Session Helper** 확장 프로그램 설치 ([설치 가이드](../appendix/band-extension.md))
2. Band(band.us)에 로그인
3. BandAuto(snsauto.abcpharm.net)에 로그인
4. Extension 아이콘 클릭 → **세션 저장하기** 클릭
5. 모든 소매 채널에 세션이 자동으로 저장됩니다

## 채널 설정

각 채널 카드에서 **설정** 버튼을 클릭하면 상세 설정을 변경할 수 있습니다:

- **채널명 수정**: 표시 이름 변경
- **Band URL 수정**: Band 주소 변경
- **활성/비활성**: 채널 사용 여부 토글
- **삭제**: 채널 삭제 (소프트 삭제)

## 주의사항

- 도매 채널에서 수집된 상품은 가공 후 소매 채널에 발행됩니다
- 소매 채널의 Band 세션은 약 14일마다 만료되므로 주기적으로 갱신해야 합니다
- 세션이 만료되면 해당 채널로의 발행이 중단됩니다
