# 상품 소싱 (게시물 수집)

도매 채널의 밴드 게시물을 자동으로 수집하고 관리하는 메뉴입니다. 소싱 조건에 맞는 게시물을 자동 수집하거나, 수동으로 채널을 탐색하여 원하는 상품을 직접 선택할 수 있습니다.

|------|------|

| 게시물 목록 | 수집된 게시물 카드 리스트 (이미지 썸네일, 제목, 채널명, 수집일) |
| 일괄 작업 버튼 | 선택된 게시물을 일괄 가공 요청하거나 삭제 |
| 게시물 상세 패널 | 우측 슬라이드 패널로 원문 게시물 내용 및 이미지 확인 |

## 주요 기능

### 게시물 자동 수집
- 등록된 도매 채널에서 Playwright를 이용해 최신 게시물을 주기적으로 크롤링합니다.
- 소싱 조건(키워드 포함/제외, 최소/최대 가격 등)에 맞는 게시물만 자동 필터링하여 저장합니다.
- 수집 주기는 **자동화 설정** 메뉴에서 조정할 수 있습니다.

### 게시물 목록 및 검색
- 수집된 모든 게시물을 카드 형태로 확인합니다.
- **채널 필터**: 특정 도매 채널의 게시물만 표시합니다.
- **날짜 필터**: 수집 기간을 설정하여 기간 내 게시물만 조회합니다.
- **키워드 검색**: 게시물 제목 또는 본문 내용을 기준으로 검색합니다.
- **상태 필터**: 미처리 / 가공 요청됨 / 가공 완료 / 발행 완료 상태별로 조회합니다.

### 게시물 상세 확인
- 목록에서 게시물을 클릭하면 우측 패널에 상세 내용이 표시됩니다.
- 원문 밴드 게시물의 제목, 본문, 첨부 이미지, 작성자, 작성일을 확인할 수 있습니다.
- **원본 보기** 버튼을 클릭하면 밴드 앱에서 해당 게시물로 바로 이동합니다.

### 가격 정보 포함 이미지 자동 삭제
도매 게시물의 이미지에는 공급가, 마진율 등 판매자에게 공개되면 안 되는 가격 정보가 표시된 경우가 있습니다. 시스템은 이런 이미지를 자동으로 감지하고 처리합니다.

- AI 이미지 분석을 통해 가격 정보(숫자, 원, ₩ 기호 등)가 포함된 이미지를 자동 감지합니다.
- 감지된 이미지는 가공 상품 생성 시 자동으로 제외됩니다.
- 상세 패널에서 삭제 대상 이미지는 **⚠️ 가격 노출** 배지로 표시됩니다.
- 설정에 따라 자동 삭제 또는 수동 확인 후 삭제를 선택할 수 있습니다.

## 사용 방법

### 수동으로 게시물 가공 요청하기

1. 게시물 목록에서 가공할 게시물의 체크박스를 선택합니다.
2. 상단 **가공 요청** 버튼을 클릭합니다.
3. 선택한 게시물이 **가공 상품** 메뉴의 대기 목록으로 이동합니다.
4. Gemini AI가 상품명, 설명, 소매 가격을 자동으로 생성합니다.

### 게시물 직접 삭제하기

1. 목록에서 삭제할 게시물을 선택합니다.
2. **삭제** 버튼을 클릭하고 확인 팝업에서 **확인**을 누릅니다.
3. 삭제된 게시물은 복구되지 않으니 주의하세요.

### 가격 이미지 수동 관리하기

1. 게시물 상세 패널에서 이미지 목록을 확인합니다.
2. **⚠️ 가격 노출** 배지가 붙은 이미지를 확인합니다.
3. 이미지 우측 상단의 **삭제** 아이콘을 클릭하여 개별 이미지를 제외합니다.
4. 변경 사항은 이후 가공 요청 시 자동으로 반영됩니다.

## 주의사항

- 자동 수집은 밴드 서버 정책에 따라 수집 속도에 제한이 있을 수 있습니다. 과도한 크롤링은 채널 접근 차단으로 이어질 수 있으니 수집 주기를 적절히 설정하세요.
- 이미 가공 요청된 게시물은 목록에서 재선택하여 중복 요청하지 않도록 주의하세요.
- 가격 정보 이미지 자동 감지는 이미지 내 텍스트 인식(OCR) 기반으로 작동하며, 감지 정확도는 이미지 품질에 따라 달라질 수 있습니다. 중요한 게시물은 수동으로 한 번 더 확인하는 것을 권장합니다.
- 수집된 게시물은 최대 90일간 보관되며, 이후 자동 삭제됩니다.
