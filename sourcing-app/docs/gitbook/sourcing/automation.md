# 자동화 설정

상품 수집, AI 가공, 발행 등 반복 작업을 자동으로 실행하는 스케줄을 설정하는 메뉴입니다. 자동화를 구성하면 등록된 일정에 따라 시스템이 수동 개입 없이 소싱 파이프라인 전체를 처리합니다.

![자동화 설정 화면](../.gitbook/assets/automation-settings.png)

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 자동화 규칙 목록 | 등록된 자동화 규칙 목록 (이름, 유형, 주기, 활성 상태) |
| 새 규칙 만들기 버튼 | 자동화 규칙 생성 마법사 열기 |
| 규칙 상세 편집 | 선택한 규칙의 조건, 주기, 동작을 수정 |
| 활성/비활성 토글 | 규칙을 일시 중단하거나 재활성화 |
| 최근 실행 현황 | 각 규칙의 마지막 실행 시간 및 결과 |

---

## 자동화 파이프라인 구성

BandAuto의 자동화는 다음 단계로 구성됩니다.

```
[1단계] 수집 → [2단계] 가공 → [3단계] 발행
```

각 단계별 자동화를 개별적으로 또는 연결하여 설정할 수 있습니다.

---

## 자동화 유형

| 유형 | 설명 |
|------|------|
| **자동 수집** | 지정된 도매 채널에서 주기적으로 새 게시물을 수집 |
| **자동 가공** | 수집된 게시물을 자동으로 Gemini AI 가공 요청 |
| **자동 발행** | 가공 완료 상품을 자동으로 소매 밴드에 발행 |
| **자동 다이제스트** | 지정 시간에 가공 완료 상품을 모아 다이제스트 발행 |
| **자동 공지** | 설정된 주기로 정기 공지를 자동 발행 |

---

## 실행 주기 옵션

| 주기 | 설명 | 권장 활용 |
|------|------|----------|
| 매시간 | N시간마다 1회 실행 | 신선식품 등 빠른 소싱이 필요한 경우 |
| 매일 특정 시간 | 하루 중 지정 시간에 1회 실행 | 일반적인 수집 및 발행 자동화 |
| 특정 요일 | 선택한 요일에만 실행 | 주간 단위 운영 채널 |
| 수동 + 조건 트리거 | 특정 조건(가공 완료 N개 이상) 충족 시 자동 실행 | 유연한 발행 제어 |

---

## 주요 설정 항목

### 자동 수집 설정
- **대상 도매 채널**: 수집할 채널을 선택합니다. (복수 선택 가능)
- **수집 주기**: 1시간 / 2시간 / 6시간 / 12시간 / 24시간 중 선택
- **최대 수집 수**: 1회 실행당 최대 수집할 게시물 수 (기본값: 20개)
- **소싱 조건 연동**: 소싱조건 설정에서 만든 필터를 적용하여 조건에 맞는 게시물만 수집
- **중복 방지**: 이미 수집된 게시물은 재수집하지 않도록 자동 처리

### 자동 가공 설정
- **트리거**: 새 게시물 수집 완료 시 자동 시작 / 지정 시간에 일괄 처리 중 선택
- **최대 동시 가공 수**: 동시에 처리할 최대 상품 수 (API 호출 제한 고려)
- **가공 대기 최대 시간**: N시간 이상 대기 중인 상품 자동 알림 발송

### 자동 발행 설정
- **대상 소매 채널**: 발행할 소매 밴드 채널을 선택합니다.
- **발행 시간대**: 하루 중 발행을 허용하는 시간 범위 (예: 오전 9시 ~ 오후 9시)
- **발행 간격**: 게시물 간 최소 대기 시간 (초 단위, 최소 30초 권장)
- **1회 최대 발행 수**: 한 번의 자동화 실행에서 발행할 최대 게시물 수
- **우선순위**: 가공 완료된 순서 / 소매 가격 높은 순 / 무작위 중 선택

## 사용 방법

### 새 자동화 규칙 만들기

1. **새 규칙 만들기** 버튼을 클릭합니다.
2. 자동화 **이름**을 입력합니다. (예: 채소/과일 일일 자동 소싱)
3. 자동화 **유형**을 선택합니다. (수집 / 가공 / 발행 / 전체 파이프라인)
4. 각 유형에 맞는 세부 설정을 구성합니다.
5. **실행 주기**를 설정합니다.
6. **저장** 버튼을 클릭합니다.
7. 규칙 목록에서 활성 토글을 켜서 자동화를 시작합니다.

### 자동화 일시 중단하기

1. 규칙 목록에서 중단할 규칙을 찾습니다.
2. **활성 토글**을 클릭하여 비활성 상태로 전환합니다.
3. 재개하려면 다시 토글을 켭니다.

## 주의사항

- 수집과 발행 자동화를 동시에 모두 활성화할 경우, 검토되지 않은 AI 생성 내용이 바로 발행될 수 있습니다. 처음에는 수집/가공만 자동화하고 발행은 수동으로 진행하는 것을 권장합니다.
- 자동 발행 간격이 너무 짧으면 밴드에서 스팸으로 감지될 수 있습니다. 게시물 간 최소 60초 이상의 간격을 설정하세요.
- 밴드 채널 세션이 만료되면 자동화가 실패합니다. 채널 세션을 정기적으로 갱신하거나, 실패 알림을 수신하도록 알림 설정을 구성하세요.
- 자동화 실행 이력은 **실행 로그** 메뉴에서 확인할 수 있습니다.
