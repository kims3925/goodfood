# AI 채팅 통합 인박스

여러 소매 밴드 채널에서 수신되는 고객 채팅 메시지를 한 곳에서 통합 관리하는 메뉴입니다. AI 자동 응답과 수동 응답을 병행하여 고객 문의를 효율적으로 처리합니다.

![AI 통합 인박스 화면](../.gitbook/assets/inbox.png)

---

## 화면 구성

| 영역 | 설명 |
|------|------|
| 채팅 목록 (좌측 패널) | 수신된 고객 채팅 목록, 채널명, 최신 메시지 미리보기, 미처리 건수 |
| 채팅 뷰어 (중앙 패널) | 선택한 고객과의 대화 내역 전체 조회 |
| 응답 입력창 (하단) | 메시지 직접 입력 또는 AI 응답 초안 수정 후 발송 |
| 고객 정보 (우측 패널) | 해당 고객의 주문 이력, 문의 이력, 메모 |
| 필터 탭 | 전체 / 미처리 / AI 처리됨 / 수동 처리됨 / 처리 완료 분류 |

## 주요 기능

### 다중 채널 통합 관리
- 여러 소매 밴드 채널의 채팅을 하나의 인박스에서 모두 확인합니다.
- 채팅 목록 상단의 채널 필터로 특정 채널의 메시지만 볼 수 있습니다.
- 새 메시지가 수신되면 알림이 발송됩니다. (알림 설정은 환경 설정에서 조정)

### AI 자동 응답
- 수신된 메시지를 AI가 분석하여 적절한 답변을 자동 생성하고 발송합니다.
- 자동 응답 활성화 여부는 **AI 자동응답 설정** 메뉴에서 채널별로 설정합니다.
- AI가 자동 응답한 메시지는 채팅 목록에서 **AI 처리됨** 배지로 표시됩니다.
- AI 자동 응답이 불확실한 경우 자동으로 **검토 필요** 상태로 전환되어 수동 응답을 요청합니다.

### 수동 응답
- AI 자동 응답이 부적절하거나 복잡한 문의는 직접 타이핑하여 응답합니다.
- AI가 생성한 초안을 수정한 뒤 발송할 수 있습니다.
- **빠른 답변 템플릿**: 자주 사용하는 문구를 저장해두고 클릭 한 번으로 입력합니다.

### 고객 주문 연동
- 채팅 우측 패널에서 해당 고객의 주문 이력을 바로 확인합니다.
- 주문 상태(접수, 준비중, 발송, 완료)를 채팅 화면에서 바로 확인하고 고객에게 안내할 수 있습니다.
- 주문 링크를 메시지에 바로 삽입할 수 있습니다.

### 메시지 분류 및 처리 상태

| 상태 | 설명 |
|------|------|
| **미처리** | 아직 응답하지 않은 새 메시지 |
| **AI 처리됨** | AI가 자동으로 응답 완료한 메시지 |
| **수동 처리됨** | 운영자가 직접 응답 완료한 메시지 |
| **검토 필요** | AI가 자동 응답에 실패하거나 판단이 어려운 메시지 |
| **처리 완료** | 문의가 해결되어 종료된 대화 |

## 사용 방법

### 고객 문의 응답하기

1. 채팅 목록에서 **미처리** 또는 **검토 필요** 상태의 채팅을 클릭합니다.
2. 중앙 패널에서 대화 내용 전체를 확인합니다.
3. 우측 패널에서 해당 고객의 주문 이력을 참고합니다.
4. 응답 입력창에 직접 메시지를 작성하거나, **AI 초안 보기** 버튼으로 AI가 제안한 답변을 확인합니다.
5. 내용을 수정한 뒤 **발송** 버튼 또는 `Enter`로 메시지를 전송합니다.
6. 문의가 해결되었으면 **처리 완료** 버튼을 클릭하여 대화를 종료합니다.

### 빠른 답변 템플릿 사용하기

1. 응답 입력창 우측의 **템플릿** 아이콘을 클릭합니다.
2. 저장된 빠른 답변 목록에서 상황에 맞는 템플릿을 선택합니다.
3. 선택한 템플릿이 입력창에 자동으로 삽입됩니다.
4. 필요한 부분(고객명, 상품명 등)을 수정한 뒤 발송합니다.
5. 자주 쓰는 문구는 **템플릿 추가** 버튼으로 새로 등록할 수 있습니다.

### 고객 메모 남기기

1. 우측 고객 정보 패널에서 **메모** 탭을 클릭합니다.
2. 메모 입력창에 참고 사항을 작성하고 저장합니다.
3. 저장된 메모는 해당 고객의 다음 문의 시에도 표시됩니다.

## 주의사항

- 밴드 채팅 메시지 수신은 Playwright를 통한 주기적 폴링 방식으로 동작합니다. 실시간 동기화가 아니므로 메시지 수신에 최대 1~3분의 지연이 발생할 수 있습니다.
- AI 자동 응답이 항상 정확한 것은 아닙니다. 주기적으로 **AI 처리됨** 탭의 대화를 확인하여 부적절한 응답이 없는지 검토하세요.
- 고객 불만, 환불 요청 등 민감한 문의는 반드시 수동으로 처리하세요. AI 자동 응답 예외 키워드 설정은 **AI 자동응답 설정** 메뉴에서 구성합니다.
- 채팅 데이터는 고객 개인정보를 포함하므로 외부에 유출되지 않도록 주의하세요.
