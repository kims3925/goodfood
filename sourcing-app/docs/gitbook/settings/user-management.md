# 매니저 관리

BandAuto 소싱 앱은 여러 명의 매니저가 함께 운영할 수 있도록 계정 관리 기능을 제공합니다. 계정 역할에 따라 접근 가능한 기능이 구분됩니다.

---

## 역할(Role) 체계

| 역할 | 설명 | 주요 권한 |
|------|------|-----------|
| **ADMIN** | 시스템 최고 관리자 | 모든 기능 접근, 매니저 초대/삭제, 시스템 설정 변경 |
| **MANAGER** | 운영 매니저 | 상품 수집·가공·발행, 주문 관리, 정산 조회, 채널 관리 |
| **USER** | 일반 사용자 | 상품 조회, 주문 조회만 가능. 설정 변경 불가 |

> 현재 로그인한 계정의 역할은 우측 상단 프로필 아이콘 옆에 뱃지로 표시됩니다.

---

## 매니저 목록 조회

1. 소싱 앱 → **설정** → **매니저 관리**로 이동합니다.
2. 등록된 모든 매니저 목록이 표시됩니다.

목록에서 확인할 수 있는 정보:

| 컬럼 | 설명 |
|------|------|
| 이름 | 매니저 표시 이름 |
| 이메일 | 로그인 이메일 |
| 역할 | ADMIN / MANAGER / USER |
| 상태 | 활성 / 비활성 / 초대 대기 중 |
| 마지막 로그인 | 최근 접속 일시 |
| 등록일 | 계정 생성일 |

---

## 새 매니저 초대

ADMIN 권한을 가진 계정만 새 매니저를 초대할 수 있습니다.

1. **매니저 관리** 페이지 → 우측 상단 **매니저 초대** 버튼 클릭
2. 초대할 매니저의 **이메일 주소**를 입력합니다.
3. 부여할 **역할**을 선택합니다 (MANAGER / USER).
4. (선택) **메시지** 입력란에 안내 문구를 입력합니다.
5. **초대 보내기** 버튼을 클릭합니다.

초대 이메일이 발송되며, 수신자가 이메일의 링크를 클릭하여 비밀번호를 설정하면 계정이 활성화됩니다.

- 초대 링크 유효 기간: **72시간**
- 유효 기간 만료 시 **매니저 목록**에서 해당 계정을 선택 → **초대 재발송** 버튼 클릭

---

## 역할 변경

1. **매니저 목록**에서 변경할 매니저를 클릭합니다.
2. **역할** 드롭다운에서 새 역할을 선택합니다.
3. **저장** 버튼을 클릭합니다.

> 현재 로그인 중인 자신의 역할은 변경할 수 없습니다. 다른 ADMIN 계정을 통해 변경해야 합니다.

---

## 계정 비활성화 / 재활성화

퇴사하거나 더 이상 접근이 필요 없는 매니저의 계정을 비활성화합니다. 계정 삭제가 아닌 비활성화이므로 이력 데이터는 보존됩니다.

1. **매니저 목록**에서 해당 매니저를 클릭합니다.
2. **계정 비활성화** 버튼을 클릭합니다.
3. 확인 팝업에서 **비활성화** 버튼을 클릭합니다.
4. 비활성화된 계정은 로그인이 차단됩니다.
5. 재활성화는 동일한 방법으로 **계정 활성화** 버튼 클릭으로 복원합니다.

---

## 내 정보 수정

현재 로그인한 자신의 정보를 수정합니다.

1. 우측 상단 프로필 아이콘 → **내 정보** 클릭
2. 수정 가능한 항목:
   - **표시 이름**: Band 알림 발송 시 발신자 이름으로 사용됩니다.
   - **이메일**: 변경 시 인증 메일이 발송됩니다.
   - **비밀번호**: 현재 비밀번호 확인 후 변경 가능합니다.
   - **알림 수신 이메일**: 내 계정 알림 전용 이메일 (설정 → 알림 설정과 별개)
   - **프로필 사진**: JPG/PNG, 5MB 이하

---

## 접속 로그 조회

ADMIN은 전체 매니저의 접속 이력을 조회할 수 있습니다.

- **매니저 관리** → **접속 로그 탭**
- 조회 기간, 매니저, IP 주소로 필터링 가능
- 비정상적인 접속 패턴 감지 시 해당 계정을 즉시 비활성화할 수 있습니다.

---

## 보안 설정

### 2단계 인증 (2FA)

- 개별 매니저가 **내 정보** → **보안** → **2단계 인증 활성화**에서 설정합니다.
- Google Authenticator 또는 이메일 OTP를 지원합니다.

### IP 접속 제한

ADMIN은 허용 IP 범위를 지정할 수 있습니다.

- **설정** → **매니저 관리** → **IP 접속 제한 탭**
- CIDR 형식으로 허용 IP 범위 입력 (예: `192.168.1.0/24`)
- 목록에 없는 IP에서 접속 시 로그인이 차단됩니다.
- 긴급 시 등록 이메일로 임시 접속 코드를 요청할 수 있습니다.
