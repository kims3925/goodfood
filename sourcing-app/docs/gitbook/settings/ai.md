# AI / API 설정

BandAuto는 상품명 가공, 후킹 문구 생성, 상품 설명 작성에 **Google Gemini API**를 사용합니다.

![AI 설정 화면](../.gitbook/assets/settings-ai.png)

---

## Google Gemini API 키 발급

API 키가 없다면 아래 절차로 발급받으세요.

1. [Google AI Studio](https://aistudio.google.com)에 접속합니다.
2. Google 계정으로 로그인합니다.
3. 좌측 메뉴에서 **Get API key** → **Create API key** 클릭합니다.
4. 프로젝트를 선택하거나 새 프로젝트를 생성합니다.
5. 생성된 API 키를 복사해 안전한 곳에 보관합니다.

> API 키는 한 번만 표시됩니다. 분실 시 새로 발급해야 합니다.

---

## API 키 등록

1. 소싱 앱 → 상단 메뉴 **설정** → **AI / API 설정**으로 이동합니다.
2. **Gemini API 키** 입력란에 발급받은 키를 붙여넣기 합니다.
3. **연결 테스트** 버튼을 클릭하여 키가 유효한지 확인합니다.
4. "연결 성공" 메시지가 나타나면 **저장** 버튼을 클릭합니다.

---

## AI 모델 선택

사용할 Gemini 모델을 선택할 수 있습니다.

| 모델 | 설명 | 권장 용도 |
|------|------|-----------|
| `gemini-1.5-flash` | 빠른 응답, 저비용 | 대량 상품 가공, 일반 운영 |
| `gemini-1.5-pro` | 높은 품질, 고비용 | 중요 상품, 고품질 문구 필요 시 |
| `gemini-2.0-flash` | 최신 플래시 모델 | 속도와 품질 균형이 필요한 경우 |

- **설정** → **AI 모델** 드롭다운에서 원하는 모델을 선택하고 저장합니다.
- 기본값은 `gemini-1.5-flash`입니다. 비용 효율을 위해 기본값 사용을 권장합니다.

## API 사용량 모니터링

### 소싱 앱 내 모니터링

**설정** → **AI / API 설정** → **사용량 현황** 탭에서 확인할 수 있습니다.

| 항목 | 설명 |
|------|------|
| 이번 달 요청 수 | 당월 누적 API 호출 횟수 |
| 총 입력 토큰 | 프롬프트에 사용된 토큰 합계 |
| 총 출력 토큰 | AI가 생성한 토큰 합계 |
| 예상 비용 | Google 공식 단가 기준 추정치 (USD) |

### Google AI Studio에서 직접 확인

1. [Google AI Studio](https://aistudio.google.com) → **API keys** 메뉴
2. 사용량 대시보드에서 일별·월별 호출 현황을 확인합니다.
3. 할당량 초과 시 자동으로 API 호출이 차단됩니다.

---

## API 사용량 한도 설정

과도한 비용 발생을 방지하기 위해 한도를 설정하세요.

- **설정** → **AI 설정** → **일일 요청 한도** 입력란에 최대 요청 수를 입력합니다.
- 한도 도달 시 해당 일의 AI 가공 작업이 중단되고 알림이 발송됩니다.
- 기본값: 일일 500회 (운영 규모에 따라 조정)

---

## AI 응답 캐시

동일한 상품명에 대해 AI 가공 결과를 캐시하여 중복 요청을 줄입니다.

- **설정** → **AI 설정** → **응답 캐시 사용** 옵션을 활성화합니다.
- 캐시 유효 기간: 기본 7일 (1~30일 범위에서 조정 가능)
- 동일 상품명이 재수집되면 캐시된 가공 결과를 재사용하여 API 비용을 절감합니다.

## 문제 해결

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| "API 키가 유효하지 않습니다" | 키 오입력 또는 만료 | API 키 재발급 후 다시 등록 |
| "할당량 초과" 오류 | 일일/월간 한도 초과 | Google AI Studio에서 한도 상향 또는 익일 재시도 |
| AI 가공 결과 품질 저하 | 모델 또는 프롬프트 문제 | 모델 업그레이드 또는 프롬프트 수정 |
| 응답 속도 느림 | Pro 모델 사용 또는 네트워크 지연 | Flash 모델로 전환 |

추가 문제는 [FAQ](../appendix/faq.md)를 참고하거나 관리자에게 문의하세요.
