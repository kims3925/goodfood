# 로그인 및 초기 설정

## 접속 정보

BandAuto 소싱 관리자 페이지는 다음 주소로 접속합니다.

```
https://snsauto.abcpharm.net
```

> 내부 네트워크 또는 허용된 IP에서만 접속이 가능할 수 있습니다. 접속이 안 될 경우 관리자에게 문의하세요.

---

## 로그인 화면

1. 위 URL로 접속하면 로그인 페이지가 나타납니다.
2. **이메일**과 **비밀번호**를 입력한 뒤 **로그인** 버튼을 클릭합니다.
3. 최초 로그인 시 관리자가 발급한 임시 비밀번호를 사용합니다.
4. 로그인에 성공하면 소싱 대시보드 홈 화면으로 이동합니다.

---

## 비밀번호 변경

최초 로그인 후 반드시 비밀번호를 변경하는 것을 권장합니다.

1. 우측 상단 프로필 아이콘 → **내 정보** 메뉴를 클릭합니다.
2. **비밀번호 변경** 항목에서 현재 비밀번호와 새 비밀번호를 입력합니다.
3. 새 비밀번호는 영문·숫자·특수문자 조합 8자 이상을 권장합니다.
4. **저장** 버튼을 클릭하면 즉시 적용됩니다.

---

## 세션 유지 및 자동 로그아웃

- 브라우저를 닫거나 일정 시간(기본 24시간) 동안 활동이 없으면 자동으로 로그아웃됩니다.
- **로그인 상태 유지** 체크박스를 선택하면 세션이 7일간 유지됩니다.
- Band 세션은 별도로 관리되며, 약 14일마다 갱신이 필요합니다. ([Band 세션 Extension 가이드](../appendix/band-extension.md) 참조)

## 초기 설정 체크리스트

처음 BandAuto를 사용하기 전에 아래 순서대로 설정을 완료하세요.

### 1단계 — 채널 등록

도매 소싱 채널(Band 그룹)과 소매 판매 채널을 등록합니다.

- **소싱 앱** → **채널 관리** → **채널 추가** 클릭
- 도매 채널: 상품을 수집할 Band 그룹의 URL 또는 그룹 ID 입력
- 소매 채널: 상품을 발행할 Band 그룹 정보 입력
- 채널 유형(도매/소매), 카테고리, 마진율 설정 후 저장

> 채널 등록 전에 해당 Band 그룹의 멤버로 가입되어 있어야 합니다.

### 2단계 — Band 세션 저장

자동화가 Band에 접근하려면 로그인 세션이 저장되어 있어야 합니다.

- Chrome Extension "Band Session Helper"를 설치합니다. ([설치 가이드](../appendix/band-extension.md) 참조)
- Band(band.us)에 로그인한 상태에서 Extension 아이콘 클릭 → **세션 저장하기** 클릭
- 소싱 앱 → **설정** → **Band 세션** 탭에서 세션 상태가 **활성**으로 표시되는지 확인합니다.

### 3단계 — AI API 설정

AI 상품 가공 기능을 사용하려면 Google Gemini API 키가 필요합니다.

- **설정** → **AI / API 설정**으로 이동
- Google Gemini API 키를 입력하고 저장합니다. ([AI 설정 가이드](./ai.md) 참조)

### 4단계 — 프롬프트 및 가격 정책 설정

- **설정** → **프롬프트 / 가격 정책**에서 AI 가공 프롬프트와 마진율을 설정합니다.
- 기본 프롬프트가 제공되므로 처음에는 기본값을 사용해도 됩니다. ([프롬프트 설정 가이드](./prompt.md) 참조)

### 5단계 — 자동화 설정

- **설정** → **자동화**에서 상품 수집·가공·발행 주기를 설정합니다.
- 초기에는 수동 실행으로 워크플로우를 확인한 뒤 자동화를 활성화하는 것을 권장합니다.

---

## 설정 완료 확인

| 항목 | 확인 방법 |
|------|-----------|
| 채널 등록 | 소싱 앱 → 채널 관리 → 등록된 채널 목록 확인 |
| Band 세션 | 설정 → Band 세션 → 상태: 활성 |
| AI API | 설정 → AI 설정 → API 키 저장 완료 |
| 프롬프트 | 설정 → 프롬프트 → 기본값 또는 커스텀 저장 완료 |
| 자동화 | 설정 → 자동화 → 스케줄 활성화 여부 확인 |

모든 항목이 완료되면 소싱 대시보드에서 상품 수집을 시작할 수 있습니다.
