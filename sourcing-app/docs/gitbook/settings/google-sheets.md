# 구글 시트 연동

BandAuto는 상품 목록, 주문 데이터, 정산 내역을 **Google Sheets**로 내보내는 기능을 지원합니다. 이를 통해 별도의 엑셀 작업 없이 실시간으로 데이터를 조회하고 공유할 수 있습니다.

---

## 사전 준비

### Google 서비스 계정 생성

구글 시트 연동에는 서비스 계정(Service Account)이 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com)에 접속합니다.
2. 프로젝트를 생성하거나 기존 프로젝트를 선택합니다.
3. **API 및 서비스** → **라이브러리** → **Google Sheets API** 검색 후 활성화합니다.
4. **API 및 서비스** → **사용자 인증 정보** → **사용자 인증 정보 만들기** → **서비스 계정** 선택합니다.
5. 서비스 계정 이름을 입력하고 생성합니다.
6. 생성된 서비스 계정 클릭 → **키** 탭 → **키 추가** → **새 키 만들기** → **JSON** 선택합니다.
7. 다운로드된 JSON 파일을 안전하게 보관합니다.

---

## 구글 시트 준비

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. 스프레드시트 URL에서 시트 ID를 복사합니다.

```
https://docs.google.com/spreadsheets/d/[시트ID]/edit
```

3. **공유** 버튼 클릭 → 서비스 계정 이메일 주소를 **편집자** 권한으로 추가합니다.
   - 서비스 계정 이메일 형식: `이름@프로젝트.iam.gserviceaccount.com`

---

## BandAuto 연동 설정

1. 소싱 앱 → **설정** → **구글 시트 연동**으로 이동합니다.
2. **서비스 계정 JSON 업로드** 버튼을 클릭하여 다운로드한 JSON 파일을 업로드합니다.
3. **스프레드시트 ID** 입력란에 복사한 시트 ID를 붙여넣기 합니다.
4. **연결 테스트** 버튼을 클릭하여 연동이 정상인지 확인합니다.
5. "연결 성공" 메시지 확인 후 **저장**합니다.

## 내보내기 데이터 종류

연동 후 아래 데이터를 구글 시트로 내보낼 수 있습니다.

### 상품 데이터

| 시트명 | 포함 컬럼 | 갱신 주기 |
|--------|-----------|-----------|
| `상품_목록` | 상품명, 원가, 판매가, 채널, 상태, 수집일 | 수동 / 자동(일 1회) |
| `발행_현황` | 게시물 ID, 발행 채널, 발행일, 조회수, 주문수 | 수동 / 자동(일 1회) |

### 주문 데이터

| 시트명 | 포함 컬럼 | 갱신 주기 |
|--------|-----------|-----------|
| `주문_목록` | 주문번호, 주문자, 상품명, 수량, 금액, 상태 | 수동 / 자동(실시간) |
| `정산_내역` | 기간, 매출합계, 원가합계, 마진, 수수료, 정산액 | 수동(월 1회) |

## 자동 내보내기 설정

정해진 시간에 자동으로 구글 시트를 업데이트합니다.

1. **설정** → **구글 시트 연동** → **자동 내보내기 탭** 클릭
2. 내보낼 데이터 종류 선택 (상품 / 주문 / 정산)
3. 실행 주기 설정 (매일 / 매주 / 매월)
4. 실행 시간 설정 (예: 매일 오전 6시)
5. **저장** 후 활성화 토글을 켭니다.

---

## 수동 내보내기

즉시 내보내기가 필요한 경우:

- **상품 관리** 페이지 → 우측 상단 **내보내기** 버튼 → **구글 시트로 내보내기** 선택
- **주문 관리** 페이지 → 동일하게 **구글 시트로 내보내기** 선택
- 내보내기 완료 후 화면 하단에 "시트 업데이트 완료" 알림이 나타납니다.

---

## 시트 구조 초기화

시트 헤더(컬럼명)가 없거나 깨진 경우:

1. **설정** → **구글 시트 연동** → **시트 초기화** 버튼 클릭
2. 선택한 시트의 헤더 행이 자동으로 생성됩니다.
3. 기존 데이터는 삭제되지 않으며, 헤더 행만 덮어씁니다.

---

## 문제 해결

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| "권한 없음" 오류 | 시트에 서비스 계정 공유 안 됨 | 스프레드시트 공유 설정에서 서비스 계정 이메일 추가 |
| "시트를 찾을 수 없음" | 잘못된 시트 ID | URL에서 시트 ID를 다시 복사하여 입력 |
| 한글 깨짐 | 인코딩 문제 | Google Sheets 자체 기능 이용 시 자동 처리됨, 별도 조치 불필요 |
| 내보내기 실패 | API 할당량 초과 | Google Cloud Console에서 Sheets API 할당량 확인 |
