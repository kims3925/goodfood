# 알림 설정

BandAuto는 주요 이벤트 발생 시 담당자에게 실시간으로 알림을 전송합니다. 알림 수신 방법과 알림 종류별 활성화 여부를 이 페이지에서 설정합니다.

---

## 알림 수신 채널

**설정** → **알림 설정** → **수신 채널 탭**으로 이동합니다.

### 이메일 알림

- 가입 시 등록한 이메일로 알림이 발송됩니다.
- **추가 이메일** 입력란에 최대 3개의 이메일 주소를 등록하여 공동 수신할 수 있습니다.
- 이메일 알림은 실시간 발송이 아닌 **배치(5분 간격)** 방식으로 모아서 발송됩니다.

### Band 메시지 알림

- 지정한 Band 그룹 또는 1:1 채팅으로 알림을 전송합니다.
- **Band 알림 채널 ID** 입력란에 알림을 받을 그룹 ID를 입력합니다.
- Band 세션이 활성 상태일 때만 발송됩니다.

### 웹훅(Webhook) 알림

외부 서비스(Slack, Teams, 자체 서버 등)로 알림을 전달합니다.

1. 수신할 서비스의 웹훅 URL을 입력합니다.
2. 페이로드 형식: JSON (`application/json`)
3. 테스트 버튼으로 웹훅 수신 여부를 확인합니다.

```json
{
  "event": "order.new",
  "timestamp": "2026-05-18T10:30:00+09:00",
  "data": {
    "order_id": "ORD-20260518-001",
    "product_name": "상품명",
    "amount": 15000,
    "buyer": "홍길동"
  }
}
```

## 알림 종류 및 설정

### 주문 알림

| 알림 항목 | 설명 | 기본값 |
|-----------|------|--------|
| 신규 주문 접수 | Band 게시물에 주문 댓글이 달렸을 때 | 활성 |
| 주문 취소 요청 | 구매자가 취소 댓글을 남겼을 때 | 활성 |
| 미처리 주문 경고 | 접수 후 N시간 이내 미확인 주문 | 활성 (기본 4시간) |
| 일일 주문 요약 | 당일 주문 현황 요약 (매일 저녁 8시) | 활성 |

**미처리 주문 경고 기준 시간**은 설정에서 1~24시간 사이로 조정할 수 있습니다.

---

### 세션 만료 알림

Band 세션이 만료되면 자동화 수집 및 발행이 불가능합니다. 사전에 알림을 받아 갱신하세요.

| 알림 항목 | 설명 | 기본값 |
|-----------|------|--------|
| 세션 만료 D-3 | 세션 만료 3일 전 사전 경고 | 활성 |
| 세션 만료 D-1 | 세션 만료 1일 전 긴급 경고 | 활성 |
| 세션 만료 즉시 | 세션 만료 감지 즉시 알림 | 활성 |
| 세션 갱신 완료 | Extension으로 세션이 갱신되었을 때 | 활성 |

세션 갱신 방법은 [Band 세션 Extension 가이드](../appendix/band-extension.md)를 참조하세요.

---

### 자동화 실행 결과 알림

| 알림 항목 | 설명 | 기본값 |
|-----------|------|--------|
| 수집 완료 | 자동 상품 수집 완료 및 수집 건수 | 비활성 |
| 수집 실패 | 수집 중 오류 발생 시 | 활성 |
| 가공 완료 | AI 가공 완료 및 처리 건수 | 비활성 |
| 가공 실패 | AI API 오류 등으로 가공 실패 시 | 활성 |
| 발행 완료 | Band 게시물 발행 성공 | 비활성 |
| 발행 실패 | 발행 오류 발생 시 | 활성 |
| 파이프라인 전체 완료 | 수집→가공→발행 전 과정 완료 요약 | 활성 |

> 정상 완료 알림(수집/가공/발행 완료)은 대량 발행 시 과도한 알림이 발생할 수 있으므로 기본값은 비활성입니다. 필요 시 활성화하세요.

---

### AI API 이상 알림

| 알림 항목 | 설명 | 기본값 |
|-----------|------|--------|
| API 사용량 80% 도달 | 일일 한도의 80% 사용 시 경고 | 활성 |
| API 한도 초과 | 일일 한도 초과로 AI 가공 중단 시 | 활성 |
| API 키 오류 | API 키 무효 또는 만료 감지 시 | 활성 |

## 알림 무음 시간 설정

야간 시간대에 알림을 받지 않으려면 무음 시간을 설정합니다.

- **설정** → **알림 설정** → **무음 시간 탭**
- 시작 시간 / 종료 시간 입력 (예: 오후 11시 ~ 오전 7시)
- 무음 시간 중 발생한 알림은 무음 시간 해제 후 일괄 전송됩니다.
- **긴급 알림** (세션 만료 즉시, 발행 실패)은 무음 시간에도 발송됩니다.

---

## 알림 이력 조회

- **설정** → **알림 설정** → **발송 이력 탭**에서 최근 30일간 발송된 알림 목록을 확인할 수 있습니다.
- 이력에서 발송 실패 항목을 선택하여 재발송할 수 있습니다.
