# 프롬프트 / 가격 정책

## 개요

BandAuto의 AI 가공 기능은 도매 채널에서 수집한 원본 상품 정보를 기반으로 소매 채널에 발행할 **후킹 제목**, **상품 설명**, **태그** 등을 자동 생성합니다. 이 페이지에서는 AI에게 전달하는 프롬프트를 커스터마이징하고, 판매 가격 계산 정책을 설정합니다.

---

## AI 가공 기본 원칙

BandAuto의 AI 가공은 다음 원칙을 따릅니다.

1. **원본 상품명 유지**: 도매 채널의 원본 상품명은 그대로 보존합니다. 소비자가 검색·비교할 수 있도록 원본명은 발행 게시물 본문에 포함됩니다.
2. **후킹 제목만 AI 수정**: 게시물 상단에 노출되는 제목(후킹 제목)만 AI가 재작성합니다. 구매 욕구를 자극하는 문구로 변환합니다.
3. **사실 기반 작성**: AI는 원본 상품 정보에 없는 내용을 임의로 추가하지 않도록 프롬프트에 명시합니다.

---

## 프롬프트 설정 화면

**설정** → **프롬프트 / 가격 정책** → **프롬프트 탭**으로 이동합니다.

### 시스템 프롬프트 (System Prompt)

AI의 역할과 규칙을 정의합니다. 기본값:

```
당신은 Band 소셜커머스 상품 판매 전문 카피라이터입니다.
도매 상품 정보를 받아 소비자의 구매 욕구를 자극하는 후킹 제목과 상품 설명을 작성합니다.
반드시 지켜야 할 규칙:
1. 원본 상품명은 절대 삭제하지 않습니다.
2. 없는 사실을 추가하거나 과장하지 않습니다.
3. 한국어로 작성합니다.
4. 이모지를 적절히 활용하여 가독성을 높입니다.
```

### 후킹 제목 프롬프트

원본 상품명을 기반으로 후킹 제목을 생성하는 지시문입니다. 기본값:

```
다음 상품의 후킹 제목을 3가지 작성해주세요.
- 20자 내외로 간결하게
- 혜택·가격·희소성 중 하나를 강조
- 클릭하고 싶은 호기심 유발

상품명: {product_name}
가격: {price}원
```

### 상품 설명 프롬프트

상품 상세 설명을 생성하는 지시문입니다.

```
다음 상품 정보를 바탕으로 Band 소셜커머스 게시물용 상품 설명을 작성해주세요.
- 300~500자 분량
- 핵심 특징 3가지 이상 포함
- 주문 방법 안내 포함 (댓글로 주문)
- 원본 상품명을 반드시 포함

상품명: {product_name}
원가: {original_price}원
판매가: {sell_price}원
상품 설명: {description}
```

### 플레이스홀더 변수

프롬프트 내에서 사용할 수 있는 변수 목록입니다.

| 변수 | 설명 |
|------|------|
| `{product_name}` | 원본 상품명 |
| `{original_price}` | 도매 원가 |
| `{sell_price}` | 계산된 판매가 |
| `{description}` | 원본 상품 설명 |
| `{category}` | 상품 카테고리 |
| `{channel_name}` | 소매 채널명 |

## 가격 정책 설정

**설정** → **프롬프트 / 가격 정책** → **가격 정책 탭**으로 이동합니다.

### 마진율 설정

도매 원가에 마진율을 적용하여 판매가를 자동 계산합니다.

```
판매가 = 도매 원가 × (1 + 마진율)
```

- **기본 마진율**: 채널 미지정 상품에 적용되는 기본값 (예: 30%)
- **채널별 마진율**: 특정 소매 채널에 다른 마진율 적용 가능
- **카테고리별 마진율**: 식품·생활용품 등 카테고리별로 마진율을 다르게 설정 가능

### 마진율 우선순위

마진율이 중복 지정된 경우 아래 우선순위를 따릅니다.

1. 상품 단위 직접 지정 (최우선)
2. 채널별 마진율
3. 카테고리별 마진율
4. 기본 마진율 (최하위)

### 가격 올림 설정

계산된 판매가를 보기 좋은 단위로 올림합니다.

| 옵션 | 예시 |
|------|------|
| 10원 단위 | 12,347원 → 12,350원 |
| 100원 단위 | 12,347원 → 12,400원 |
| 1,000원 단위 | 12,347원 → 13,000원 |

### 최소·최대 마진 금액 제한

- **최소 마진**: 마진율 계산 결과가 이 금액 미만이면 최소 마진금액으로 보정
- **최대 마진**: 고가 상품의 과도한 마진을 제한

## 프롬프트 테스트

설정 저장 전에 샘플 상품으로 테스트할 수 있습니다.

1. **프롬프트 테스트** 버튼 클릭
2. 테스트할 상품명과 원가를 입력합니다.
3. **생성** 버튼 클릭 후 AI 결과물을 미리 확인합니다.
4. 결과가 만족스러우면 **저장**합니다.
