# 자주 묻는 질문 (FAQ)

---

## Band 세션 관련

**Q1. Band 세션이 만료되었을 때 어떻게 해야 하나요?**

Band 세션은 약 14일마다 만료됩니다. 만료 시 자동 수집·발행이 중단됩니다.

1. Chrome에서 band.us에 로그인합니다.
2. snsauto.abcpharm.net에도 로그인합니다.
3. Chrome 우측 상단의 **Band Session Helper** Extension 아이콘 클릭 → **세션 저장하기** 클릭합니다.
4. 소싱 앱 → 설정 → Band 세션에서 상태가 **활성**으로 바뀌는지 확인합니다.

자세한 방법은 [Band 세션 Extension 가이드](./band-extension.md)를 참조하세요.

---

**Q2. 세션을 저장했는데도 "세션 만료" 상태로 표시됩니다.**

아래를 순서대로 확인하세요.

1. 소싱 앱 페이지를 새로고침(F5)합니다.
2. Extension의 사이트 접근 권한에 `band.us`와 `abcpharm.net`이 포함되어 있는지 확인합니다.
3. Chrome을 완전히 종료 후 재시작하고 세션 저장을 다시 시도합니다.
4. 그래도 해결되지 않으면 소싱 앱에서 로그아웃 후 재로그인하고 세션 저장을 반복합니다.

---

## AI 가공 관련

**Q3. AI 가공이 실행되지 않거나 오류가 납니다.**

주로 API 키 문제나 할당량 초과가 원인입니다.

1. 소싱 앱 → 설정 → AI / API 설정에서 API 키가 올바르게 입력되어 있는지 확인합니다.
2. **연결 테스트** 버튼을 눌러 API 키 유효 여부를 확인합니다.
3. 오류 메시지가 "할당량 초과"라면 [Google AI Studio](https://aistudio.google.com)에서 사용량을 확인합니다.
4. API 키를 재발급하여 다시 등록합니다.

---

**Q4. AI가 생성한 후킹 제목의 품질이 낮습니다.**

프롬프트를 수정하면 결과 품질을 높일 수 있습니다.

1. 소싱 앱 → 설정 → 프롬프트 / 가격 정책으로 이동합니다.
2. **후킹 제목 프롬프트**를 수정합니다. 구체적인 예시를 추가할수록 품질이 향상됩니다.
3. AI 모델을 `gemini-1.5-flash`에서 `gemini-1.5-pro`로 변경하면 품질이 향상되지만 비용이 증가합니다.
4. **프롬프트 테스트** 기능으로 변경 전 미리 결과를 확인하세요.

## 발행 관련

**Q5. Band 게시물 발행이 실패합니다.**

다음을 확인하세요.

1. **Band 세션 상태**: 설정 → Band 세션에서 **활성** 여부를 먼저 확인합니다. 세션 만료가 가장 흔한 원인입니다.
2. **채널 설정**: 발행 대상 채널이 소매 채널로 등록되어 있는지 확인합니다.
3. **Band 그룹 권한**: 해당 Band 그룹에서 게시물 작성 권한이 있는지 확인합니다. 멤버 등급 제한이 있을 수 있습니다.
4. 실패 로그를 확인하려면 소싱 앱 → 발행 관리 → **실패 로그** 탭에서 상세 오류 내용을 확인합니다.

---

**Q6. 발행은 됐는데 이미지가 안 보입니다.**

이미지 URL이 만료되었거나 접근이 제한된 경우입니다.

1. 수집된 상품의 원본 이미지 URL이 유효한지 확인합니다. (도매 채널에서 이미지 삭제 등)
2. 소싱 앱 → 상품 관리에서 해당 상품의 이미지를 **재다운로드** 또는 **직접 업로드**합니다.
3. 이미지를 BandAuto 서버에 먼저 업로드한 뒤 발행하는 방식을 사용하려면 설정 → 발행 설정 → **이미지 미러링** 옵션을 활성화합니다.

---

## 자동화 관련

**Q7. 자동화를 설정했는데 지정한 시간에 실행되지 않습니다.**

1. 소싱 앱 → 설정 → 자동화에서 해당 스케줄의 **활성화 토글**이 켜져 있는지 확인합니다.
2. 서버 시간대와 설정한 시간대가 맞는지 확인합니다. (서버 기준 시간: KST)
3. Band 세션이 만료되어 자동화가 내부적으로 중단된 경우가 있습니다. 세션을 갱신 후 다시 확인합니다.
4. 소싱 앱 → 자동화 → **실행 로그** 탭에서 마지막 실행 시각과 결과를 확인합니다.

---

**Q8. 자동화가 너무 자주 실행되어 Band 그룹에 스팸처럼 보입니다.**

발행 빈도를 줄이거나 발행 간격을 늘리세요.

1. 설정 → 자동화 → 해당 스케줄 편집
2. **발행 간격**(예: 게시물 간 최소 30분)을 설정합니다.
3. **일일 최대 발행 수**를 제한합니다.
4. Band 그룹 운영 정책에 맞는 발행 빈도를 유지하는 것을 권장합니다.

## 가격 / 정산 관련

**Q9. 상품 가격이 예상과 다르게 책정됩니다.**

가격은 마진율과 올림 설정에 따라 계산됩니다.

1. 설정 → 프롬프트 / 가격 정책 → **가격 정책 탭**에서 기본 마진율을 확인합니다.
2. 해당 채널에 별도의 채널별 마진율이 지정되어 있는지 확인합니다.
3. 카테고리별 마진율이 기본 마진율을 덮어쓰고 있는지 확인합니다.
4. **가격 올림 설정**에 의해 단위 올림이 적용되고 있는지 확인합니다.
5. 상품 단위로 마진율을 직접 지정한 경우 해당 값이 최우선 적용됩니다.

---

**Q10. 주문이 들어왔는데 시스템에서 감지되지 않습니다.**

BandAuto는 Band 게시물의 댓글을 주문으로 감지합니다.

1. 해당 게시물이 BandAuto를 통해 발행되었는지 확인합니다. (외부 발행 게시물은 감지 불가)
2. 주문 감지 키워드가 설정되어 있는지 확인합니다. (설정 → 주문 설정 → 주문 키워드)
3. Band 세션이 활성 상태인지 확인합니다. 세션 만료 시 댓글 감지가 중단됩니다.
4. 수동으로 주문을 추가하려면 소싱 앱 → 주문 관리 → **주문 수동 등록** 기능을 사용합니다.

---

**Q11. Band 그룹에서 매니저가 아닌 일반 멤버로만 가입되어 있는데 발행이 가능한가요?**

일반 멤버도 게시물 작성 권한이 있다면 발행이 가능합니다. 단, 그룹 설정에서 특정 등급 이상만 게시물을 작성할 수 있도록 제한되어 있다면 발행이 실패합니다. Band 그룹 설정에서 게시물 작성 권한을 확인하거나, 그룹 운영자에게 매니저 권한을 요청하세요.

---

**Q12. 구글 시트 내보내기가 실패합니다.**

1. 설정 → 구글 시트 연동에서 **연결 테스트** 버튼을 눌러 연결 상태를 확인합니다.
2. 스프레드시트 공유 설정에 서비스 계정 이메일이 **편집자** 권한으로 추가되어 있는지 확인합니다.
3. 시트 ID가 올바른지 확인합니다. (URL에서 `/d/` 다음 `/edit` 이전 부분)
4. Google Sheets API가 Cloud Console 프로젝트에서 활성화되어 있는지 확인합니다.

---

**Q13. 소싱 앱에 접속이 되지 않습니다.**

1. 인터넷 연결 상태를 확인합니다.
2. 접속 URL(`https://snsauto.abcpharm.net`)이 올바른지 확인합니다.
3. IP 접속 제한이 설정된 경우 허용된 IP에서 접속하고 있는지 확인합니다.
4. 브라우저 캐시를 삭제(Ctrl+Shift+Delete)하고 다시 시도합니다.
5. 위 방법으로도 해결되지 않으면 ADMIN에게 서버 상태를 문의합니다.
