# 쇼핑몰 Referrer 기반 정산 시스템 안내서

작성일: 2025.12.04

---

## 1. 이 문서는 무엇인가요?

쇼핑몰에서 **"어떤 소매밴드를 통해 고객이 들어왔는지"**를 추적하고,
그에 따라 **정산을 나누는 새로운 시스템**에 대한 설명입니다.

---

## 2. 왜 바꾸나요?

### 기존 방식의 문제점

현재는 같은 상품이라도 소매밴드마다 따로 등록됩니다.

예를 들어, "사과 1박스" 상품이 있다면:
- A밴드용 사과 1박스
- B밴드용 사과 1박스
- C밴드용 사과 1박스

이렇게 **같은 상품이 여러 개로 나뉘어** 관리됩니다.

쇼핑몰에서도 업체별로 섹션이 나뉘어서 고객 입장에서 혼란스럽습니다.

### 새로운 방식의 장점

쇼핑몰에는 **"사과 1박스" 하나만** 등록됩니다.

대신, 고객이 **어디서 링크를 클릭해서 들어왔는지**를 추적합니다.
- A밴드 게시물 클릭 → 구매 시 A에 정산
- B밴드 게시물 클릭 → 구매 시 B에 정산
- 직접 쇼핑몰 방문 → 자체 수익

---

## 3. 어떻게 작동하나요?

### 고객의 구매 여정

```
1. 소매밴드(A밴드)에서 상품 게시물을 봅니다
2. "구매하기" 버튼을 클릭합니다
3. 쇼핑몰 상품 페이지로 이동합니다 (이때 A밴드에서 왔다는 정보가 저장됩니다)
4. 장바구니에 담습니다 (장바구니에도 A밴드 정보가 저장됩니다)
5. 결제합니다
6. 정산 시 A밴드에 수익이 귀속됩니다
```

### 여러 밴드에서 상품을 담은 경우

고객이 이렇게 쇼핑했다면:
- A밴드에서 "사과" 클릭 → 장바구니 담기
- B밴드에서 "배" 클릭 → 장바구니 담기
- 한꺼번에 결제

결과:
- **사과는 A밴드에 정산**
- **배는 B밴드에 정산**

각 상품마다 어디서 왔는지를 따로 기억하기 때문에 공정하게 나눠집니다.

---

## 4. 정산 규칙

### 기본 규칙: 마지막 클릭 기준 (Last Click)

고객이 여러 밴드를 거쳐서 왔다면, **마지막으로 클릭한 밴드**에 정산됩니다.

| 상황 | 정산 대상 |
|------|----------|
| A밴드 클릭 → 이탈 → B밴드 클릭 → 구매 | **B밴드** |
| A밴드 클릭 → 바로 구매 | **A밴드** |
| 직접 쇼핑몰 방문 → 구매 | **자체 수익** |

### 유효 기간: 7일

고객이 A밴드 링크를 클릭하고 7일 이내에 구매하면 A밴드에 정산됩니다.
7일이 지나면 기록이 사라지고, 직접 방문으로 처리됩니다.

| 상황 | 정산 대상 |
|------|----------|
| A밴드 클릭 → 3일 후 구매 | **A밴드** |
| A밴드 클릭 → 8일 후 구매 | **자체 수익** (7일 초과) |

## 5. 쇼핑몰 화면 변화

### 변경 전
```
쇼핑몰 메인
├── A업체 상품들
├── B업체 상품들
├── C업체 상품들
└── 자사몰 상품들
```

### 변경 후
```
쇼핑몰 메인
└── 전체 상품 목록 (업체 구분 없음)
```

고객은 더 이상 "이 상품이 어느 업체 것인지" 신경 쓸 필요가 없습니다.
그냥 원하는 상품을 고르면 됩니다.

---

## 6. 소매밴드 운영자가 알아야 할 것

### 상품 링크 형식

소매밴드에 상품을 올릴 때, 링크 끝에 자동으로 추적 코드가 붙습니다.

```
https://쇼핑몰주소/product/123?ref=5
```

여기서 `ref=5`가 "5번 채널(소매밴드)에서 왔다"는 표시입니다.

### 정산 확인

- 내 채널을 통해 들어온 주문 수
- 내 채널을 통해 발생한 매출
- 최근 7일/30일 실적

---

### Q: 고객이 링크 없이 직접 쇼핑몰에 들어오면?
A: "직접 접근"으로 분류되어 자체 수익이 됩니다.

### Q: 고객이 A밴드 링크로 들어왔다가 다른 상품을 구매하면?
A: 해당 상품도 A밴드 정산입니다. 어떤 상품이든 A밴드를 통해 들어온 세션이므로.

### Q: 고객이 A밴드로 상품1을 담고, B밴드로 상품2를 담으면?
A: 상품1은 A밴드, 상품2는 B밴드에 각각 정산됩니다.

### Q: 추적 정보는 어디에 저장되나요?
A: 고객의 브라우저 쿠키와 장바구니에 저장됩니다. 쿠키를 차단해도 장바구니에 남아있어서 추적됩니다.

### Q: 기존 주문 데이터는 어떻게 되나요?
A: 기존 주문은 그대로 유지됩니다. 새 시스템 적용 후 발생하는 주문부터 추적됩니다.

---

## 8. 정리

| 항목 | 기존 | 변경 후 |
|------|------|---------|
| 쇼핑몰 상품 | 채널별로 따로 등록 | **하나로 통합** |
| 소매밴드 역할 | 상품을 직접 판매 | **유입 경로 (광고판)** |
| 정산 기준 | 어떤 채널 상품인가 | **어떤 채널을 통해 왔는가** |
| 고객 경험 | 업체별로 분리된 상품 | **통합된 상품 목록** |
