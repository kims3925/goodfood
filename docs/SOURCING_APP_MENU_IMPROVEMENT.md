## 2. 발견된 문제점

### 2.1 메뉴 중복/혼란

| 문제 | 위치 | 상세 |
|------|------|------|
| **대시보드 중복** | 소싱 대시보드 | `/sourcing/dashboard/automation`은 실제로 "자동화 대시보드"인데 메뉴명은 "대시보드" |
| **발행 메뉴 중복** | 상품 > 발행상품 vs 발행 | 두 메뉴가 유사한 역할, 구분 불명확 |
| **설정 분산** | 자동화 > 설정 vs 설정 메뉴 | 설정이 두 곳에 흩어져 있음 |

### 2.2 누락된 메뉴/기능

| 누락 항목 | 필요성 | 우선순위 |
|-----------|--------|----------|
| **통계/리포트** | 소싱 성과, 발행 현황 분석 필수 | 🔴 높음 |
| **수동 수집 버튼** | 대시보드에서만 가능, 게시물 페이지에 필요 | 🟡 중간 |
| **알림/이벤트 로그** | 시스템 이벤트, 오류 알림 확인 | 🟡 중간 |
| **사용자 관리** | 주석처리됨 (`/shop/user/list`), 필요 | 🟡 중간 |
| **계정 설정** | 비밀번호 변경, 프로필 수정 없음 | 🟡 중간 |
| **도움말/가이드** | 신규 사용자 온보딩 | 🟢 낮음 |

### 2.3 숨겨진/접근 불가 페이지

| 페이지 | 경로 | 상태 |
|--------|------|------|
| 사용자 관리 | `/shop/user/list` | 메뉴에서 제외 (주석) |
| 사용자 상세 | `/shop/user/[id]` | 페이지 존재하나 접근 경로 없음 |
| Admin 페이지 | `/admin/products` | 네비게이션에 없음 |

### 2.4 용어/네이밍 불일치

| 현재 | 문제점 | 제안 |
|------|--------|------|
| 수집상품 | "게시물"과 혼동 | "AI 대기상품" |
| 가공상품 | 의미 모호 | "등록상품" 또는 "완성상품" |
| 발행상품 | 발행 메뉴와 중복 | "발행완료" |
| 게시물 | 원문 게시물? 수집된 글? | "수집 게시물" |

### 2.5 정보 구조(IA) 문제

```
현재 흐름:
채널 → 게시물 → 수집상품 → 가공상품 → 발행상품 → 발행

문제:
- 5단계 파이프라인인데 메뉴가 3그룹으로 분리
- "수집" 그룹에 채널/게시물/수집상품 혼재
- "상품" 그룹에 가공상품/발행상품 혼재
- "발행" 메뉴가 별도로 존재
```

## 3. 개선 제안

### 3.1 소싱 섹션 메뉴 재구성 (안 1: 프로세스 중심)

```
📊 대시보드                    ← 유지

📥 소싱 ▼                      ← "수집" → "소싱"으로 변경
├─ 채널 관리
├─ 수집 게시물                 ← "게시물" → "수집 게시물"
└─ AI 대기상품                 ← "수집상품" → "AI 대기상품"

📦 상품 ▼
├─ 상품 목록                   ← "가공상품" → "상품 목록"
└─ 발행 현황                   ← "발행상품" → "발행 현황"

🚀 발행                        ← 유지 또는 상품 하위로 이동

📈 통계 ▼                      ← 신규 추가
├─ 소싱 현황
├─ 발행 분석
└─ 채널별 성과

⚡ 자동화 ▼
├─ 설정
└─ 실행 로그

⚙️ 설정 ▼
├─ 정책
├─ API 연동
├─ AI 설정
└─ 프롬프트
```

### 3.2 소싱 섹션 메뉴 재구성 (안 2: 파이프라인 시각화)

```
📊 현황판                      ← 대시보드를 "현황판"으로

🔄 파이프라인 ▼                ← 프로세스 단계 명확화
├─ 1. 채널 관리
├─ 2. 게시물 수집
├─ 3. AI 변환
├─ 4. 상품 등록
└─ 5. 밴드 발행

📦 상품 ▼
├─ 전체 상품
└─ 발행 완료

📈 분석
├─ 일간 리포트
└─ 채널 성과

⚡ 자동화 ▼
├─ 스케줄 설정
└─ 실행 이력

⚙️ 설정 ▼
├─ 가격 정책
├─ API 키
├─ AI 모델
└─ 프롬프트
```

### 3.3 쇼핑몰 섹션 메뉴 재구성

```
📊 대시보드

🏪 쇼핑몰 ▼                    ← 그룹화
├─ 쇼핑몰 목록
└─ 상점 설정                   ← 신규: 쇼핑몰별 설정

📋 주문 ▼
├─ 주문 목록
├─ 발주 관리
└─ 발주 이력

💰 정산 ▼
├─ 정산 목록
└─ 정산 이력

👥 고객 ▼                      ← 그룹화
├─ 고객 문의
├─ 고객 목록                   ← 신규
└─ 리뷰 관리                   ← 신규

🎫 마케팅 ▼                    ← 쿠폰을 마케팅으로 확장
├─ 쿠폰 관리
└─ 프로모션                    ← 신규 (추후)

👤 사용자 관리                 ← 주석 해제 필요
```

## 5. 중기 개선 과제

### 5.1 통계 페이지 신규 개발

**소싱 통계** (`/sourcing/stats`)
- 일간/주간/월간 수집량
- AI 변환 성공률
- 채널별 발행 현황
- 발행 성공률 추이

**판매 통계** (`/shop/stats`)
- 일간 주문량/매출
- 상품별 판매 순위
- 채널별 성과 비교

### 5.2 알림 센터 개발

**경로:** `/notifications`

**기능:**
- 자동화 실패 알림
- 신규 주문 알림
- 재고 부족 경고
- 정산 완료 알림

### 5.3 계정 설정 페이지

**경로:** `/settings/account`

**기능:**
- 프로필 수정
- 비밀번호 변경
- 알림 설정
- 로그인 이력

## 6. UI/UX 개선 제안

### 6.1 대시보드 진입점 문제

**현재:**
- 소싱 대시보드: `/sourcing/dashboard/automation`
- 쇼핑몰 대시보드: `/shop/dashboard`

**문제:**
- 소싱은 `/sourcing` 진입 시 `/sourcing/dashboard/automation`으로 리다이렉트
- 통합 대시보드가 없음

**제안:**
- 진입 시 섹션 선택 화면 또는 통합 대시보드 제공
- 또는 최근 접속 섹션 기억

### 6.2 빠른 액션 개선

**현재 Header:**
- "전체 실행" 버튼만 존재

**제안:**
```
빠른 액션 추가:
- 수집 실행
- AI 변환 실행
- 발행 실행
- 통계 보기
```

### 6.3 브레드크럼 추가

```
현재: 페이지 제목만 표시

제안:
소싱 > 상품 > 상품 목록
쇼핑몰 > 주문 > 주문 상세 > #12345
```

### 6.4 탭 전환 개선

**현재:**
- 헤더에서 "소싱 | 쇼핑몰" 버튼으로 전환

**문제:**
- 모바일에서 탭 전환 버튼 작음
- 현재 섹션 인지 어려움

**제안:**
- 사이드바 상단에 명확한 섹션 인디케이터
- 다른 색상 테마로 섹션 구분
