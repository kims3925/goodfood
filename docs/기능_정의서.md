# BandAuto 기능 정의서

## 📋 프로젝트 개요
밴드 자동화 시스템의 핵심 기능을 정의합니다.

---

## 🎯 핵심 기능 목록

### 1. 로그인/회원가입 기능
**설명:** 사용자 인증 및 계정 관리 시스템

**세부 기능:**
- 회원가입 (이메일, 비밀번호)
- 로그인/로그아웃
- 세션 관리
- Band API 연동을 위한 OAuth 인증

**구현 상태:** ✅ 완료 (NextAuth.js v4)

**관련 파일:**
- `app/(auth)/login/page.tsx`
- `app/(auth)/register/page.tsx`
- `lib/auth.ts`

### 2. 사용자의 밴드목록 조회 및 DB에 저장
**설명:** Band API를 통해 사용자가 가입한 모든 밴드 목록을 조회하고 데이터베이스에 저장

**세부 기능:**
- Band API를 통한 밴드 목록 조회
- 조회된 밴드 정보를 데이터베이스에 저장
- 밴드 정보 업데이트 (주기적 동기화)
- 밴드 목록 UI 표시

**데이터베이스 모델:**
- User (Band API 토큰 저장)
- WholesaleBand (도매 밴드 정보)
- RetailBand (소매 밴드 정보)

**구현 필요 사항:**
- [ ] Band API 밴드 목록 조회 API 엔드포인트
- [ ] 밴드 정보 동기화 로직
- [ ] 밴드 목록 표시 UI

**예상 API 구조:**
```typescript
GET /api/band/list
POST /api/band/sync
```

- 밴드 목록에서 도매 밴드 선택 UI

**데이터베이스 모델:**
- WholesaleBand (도매 밴드 정보 + 가격정책)

**구현 필요 사항:**

- [ ] 도매 밴드 등록 API
- [ ] 가격정책 설정 인터페이스

### 4. 도매 밴드 게시물 수집 및 재구성 후 소매 밴드에 포스팅
**설명:** 도매 밴드의 게시물을 자동으로 수집하고, AI를 통해 재구성한 후 선택한 소매 밴드에 자동으로 게시

**세부 기능:**

#### 4-1. 도매 밴드 게시물 수집
- Playwright를 통한 밴드 크롤링
- 게시물 내용, 이미지, 가격 정보 추출
- 댓글에서 추가 정보 파싱
- 수집된 데이터 DB 저장

#### 4-2. AI 게시물 재구성
- Gemini AI를 통한 상품 분석
- 20자 고정 제목 생성
- 5단계 카테고리 자동 분류
- 가격정책 자동 적용
- 매력적인 상품 설명 생성

#### 4-3. 소매 밴드 선택 및 포스팅
- 재구성된 게시물을 올릴 소매 밴드 선택
- 자동 포스팅 실행
- 포스팅 결과 추적

**데이터베이스 모델:**
- WholesaleBand (도매 밴드 정보)
- CollectedPost (수집된 게시물 + AI 분석 결과)
- RetailBand (소매 밴드 정보)
- RetailSettings (소매 밴드 포스팅 설정)
- RetailPost (소매 밴드 게시물 관리)

**구현 상태:**
- ✅ 게시물 수집 기능 완료
- ✅ AI 분석 완료 (lib/gemini-ai.ts)
- 🚧 소매 밴드 자동 포스팅 90% 완료

**구현 필요 사항:**
- [ ] 소매 밴드 선택 UI 개선
- [ ] 자동 포스팅 스케줄링
- [ ] 포스팅 성공/실패 알림

**예상 API 구조:**
```typescript
POST /api/wholesale/collect          // 게시물 수집
POST /api/ai/analyze                 // AI 분석
POST /api/retail/post                // 소매 밴드 포스팅
GET /api/retail/posts/status         // 포스팅 상태 조회
```

### 5. 소매 밴드 게시물을 쇼핑몰에도 등록
**설명:** 소매 밴드에 올린 게시물을 자동으로 쇼핑몰 상품으로도 등록

**세부 기능:**
- 소매 밴드 게시물 → 쇼핑몰 상품 자동 변환
- 쇼핑몰 상품 정보 최적화
- SEO 최적화된 상품 페이지 생성
- 쇼핑몰 URL을 소매 밴드 게시물에 포함

**데이터베이스 모델:**
- RetailPost (소매 밴드 게시물)
- Shop (쇼핑몰 정보)
- ShopProduct (쇼핑몰 상품)
- ProductPage (SEO 최적화 상품 페이지)

**구현 상태:**
- ✅ Shop 모델 완료
- ✅ ShopProduct 모델 완료
- ✅ ProductPage 모델 완료
- ❌ 자동 연동 로직 미구현

**구현 필요 사항:**
- [ ] 소매 밴드 게시물 → 쇼핑몰 상품 자동 변환 API
- [ ] 쇼핑몰 상품 등록 UI
- [ ] 쇼핑몰 URL 자동 삽입 로직

**예상 API 구조:**
```typescript
POST /api/shop/products/from-retail  // 소매 게시물 → 쇼핑몰 상품 변환
PUT /api/shop/products/{id}          // 쇼핑몰 상품 업데이트
```

### 6. 자동화/수동 모드 선택 기능
**설명:** 각 단계별로 자동화 또는 수동 처리를 선택할 수 있는 기능

**세부 기능:**

#### 6-1. 게시물 수집 자동화
- **자동 모드:** 정해진 주기로 자동 수집
- **수동 모드:** 사용자가 직접 수집 버튼 클릭

#### 6-2. AI 분석 자동화
- **자동 모드:** 수집 즉시 AI 분석 실행
- **수동 모드:** 사용자가 게시물 선택 후 분석

#### 6-3. 소매 밴드 포스팅 자동화
- **자동 모드:** 분석 완료 후 자동으로 선택된 밴드에 포스팅
- **수동 모드:** 사용자가 게시물 검토 후 포스팅

#### 6-4. 쇼핑몰 등록 자동화
- **자동 모드:** 소매 밴드 포스팅 후 자동으로 쇼핑몰 등록
- **수동 모드:** 사용자가 쇼핑몰 등록 여부 선택

**설정 구조:**
```typescript
interface AutomationSettings {
  autoCollect: boolean           // 자동 수집
  collectInterval: number        // 수집 주기 (분)
  autoAnalyze: boolean           // 자동 AI 분석
  autoPostToRetail: boolean      // 자동 소매 밴드 포스팅
  autoAddToShop: boolean         // 자동 쇼핑몰 등록
  notifyOnComplete: boolean      // 완료 알림
  notifyOnError: boolean         // 에러 알림
}
```

**데이터베이스 모델:**
- RetailSettings (소매 밴드별 자동화 설정)
- ShopSettings (쇼핑몰 자동화 설정)

**구현 필요 사항:**
- [ ] 자동화 설정 UI
- [ ] 자동화 스케줄러 (Bull Queue)
- [ ] 자동화 작업 모니터링 대시보드
- [ ] 알림 시스템 (이메일/SMS)

**예상 API 구조:**
```typescript
GET /api/automation/settings         // 자동화 설정 조회
PUT /api/automation/settings         // 자동화 설정 업데이트
POST /api/automation/start           // 자동화 시작
POST /api/automation/stop            // 자동화 중지
GET /api/automation/status           // 자동화 상태 조회
```
